# VS Code: агент внутри редактора

Всё это работает через один и тот же роутер (`http://127.0.0.1:8788/v1`), поэтому
расширения делят лимиты, и панель <http://127.0.0.1:8788/> показывает всё разом.

Перед началом: **роутер должен быть запущен** (`windows\START-ROUTER.bat`).

---

## Вариант 1. Cline — самый популярный агент для VS Code (67k★)

Автономный агент: сам читает файлы, сам правит, показывает diff и просит подтверждение.

1. VS Code → расширения → найдите **Cline** → Install.
2. Откройте Cline (иконка на панели слева) → **Settings**.
3. **API Provider** = `OpenAI Compatible`.
4. Заполните:
   * **Base URL**: `http://127.0.0.1:8788/v1`
   * **API Key**: `freecoder` (любая строка — роутеру всё равно)
   * **Model ID**: `smart`  (варианты: `auto`, `fast`, `local`)
   * **Context Window**: `128000`, **Max Output**: `8192` (если поля есть)
5. Нажмите **Done** и пишите задачу в чат Cline.

Полезно: включите «Auto-approve» только для чтения файлов; правки лучше подтверждать
глазами первые дни.

## Вариант 2. Kilo Code — много режимов (Code / Architect / Debug)

1. VS Code → расширения → **Kilo Code** → Install.
2. Settings → Provider = `OpenAI Compatible`, Base URL `http://127.0.0.1:8788/v1`,
   API Key `freecoder`, Model `smart`.
3. Режимы переключаются на панели: Architect — «подумать и спланировать»,
   Code — «сделать», Debug — «починить».

## Вариант 3. Continue — чат, правки и автодополнение

Конфиг уже подготовлен в этом репозитории: `vscode\continue-config.yaml`.

1. Установите расширение **Continue**.
2. Скопируйте конфиг:
   ```powershell
   copy vscode\continue-config.yaml "$env:USERPROFILE\.continue\config.yaml"
   ```
   (если файл уже есть — добавьте блок `models` из нашего конфига в свой)
3. Перезагрузите VS Code. В выпадающем списке моделей появятся
   **FreeCoder smart / auto / fast / local**.

## Вариант 4. Roo Code / другие форки

Логика та же: ищите в настройках провайдер **OpenAI Compatible** и вписывайте
base URL `http://127.0.0.1:8788/v1`, ключ `freecoder`, модель `smart`.

---

## Какие модели выбирать в редакторе

| Модель | Когда |
|---|---|
| `smart` | сложные многофайловые задачи, рефакторинг |
| `auto` | обычная работа (роутер сам выберет живого провайдера) |
| `fast` | мелкие правки, быстрые вопросы (экономно) |
| `local` | код, который нельзя отправлять в облако |

## Если расширение не видит роутер

* Проверьте, что роутер жив: <http://127.0.0.1:8788/health> должен вернуть `{"status":"ok"}`.
* Base URL обязательно с `/v1` на конце и без лишнего слэша.
* Если расширение требует «валидный ключ» — впишите `freecoder`; проверок ключа роутер не делает.
* Ошибка 429 в чате расширения = все бесплатные квоты на сегодня исчерпаны.
  Смотрите панель роутера, добавьте ключ другого сервиса или включите локальную модель.
* Ошибка 400 с упоминанием `tools` не страшна: роутер сам повторит запрос без
  неподдерживаемых полей.

## Стоит ли ставить ещё и GitHub Copilot / Cursor?

Бесплатные тарифы Copilot (2000 автодополнений и 50 чатов/мес) и Cursor (50 запросов)
— полезны как «второй инструмент», но они быстро кончаются и не умеют автономно править
файлы так, как Cline/Kilo с нашим роутером. Комбинировать можно: автодополнение — Copilot,
агентные задачи — Cline + FreeCoder.
