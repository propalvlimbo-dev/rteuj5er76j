# ELYTRIX — компактный ИИ-агент для консоли

Агент, который **читает ваши файлы и сам их правит**: пишет код, чинит тесты, запускает
сборку, откатывает неудачные правки. Работает на вашем ключе SmartAPI (`sk-smart-…`) —
один ключ, один шлюз, никакого локального HTTP-посредника между агентом и моделью.

Весь проект — **7 700 строк на чистой стандартной библиотеке Python**: ни одной сторонней
зависимости, ни `pip install`, ни Node.js. Интерфейс нарисован самим агентом — ANSI-код,
полноэкранный режим, свои виджеты.

```
   вы (задача словами)
        │
        ▼
   ELYTRIX  ── учёт токенов, дневной лимит, коэффициенты моделей,
        │       промпт-кэш, сжатие истории, песочница, откат правок
        ▼
   https://api.smartapi.shop     формат Anthropic (основной)
        │                        формат OpenAI    (запасной)
        ▼
   ваш баланс SmartAPI
```

Отдельный режим `--router` поднимает OpenAI-совместимый шлюз на `127.0.0.1:8789` —
только если вы работаете в Cline, Continue, Kilo Code, opencode или Cursor.
**Само́й консоли роутер не нужен**: она говорит со шлюзом напрямую, без лишнего хопа.

---

## Запуск: три шага

**1. Python 3.8+** — проверить: `python --version`.
Нет — поставить с <https://www.python.org/downloads/>, обязательно с галочкой
**Add Python to PATH**.

**2. Ключ** — кабинет <https://smartapi.shop/api-keys>, создать ключ `sk-smart-…`.

**3. Двойной клик:**

```
ELYTRIX.bat
```

Windows откроет консоль в UTF-8 и полноэкранном режиме. Linux и macOS — то же самое
командой `python3 app/run.py`.

При первом запуске агент спросит ключ (символы не отображаются — это нормально) и папку
с вашим кодом. Ключ сохранится в профиль `~/.elytrix/credentials.json` с правами `600`
и в переменную окружения `SMARTAPI_KEY`; папка запомнится, дальше достаточно Enter.

## Как это выглядит

```
 ELYTRIX 3.4.0                    claude-sonnet-4-6 ×2 │ my-project │ ask
──────────────────────────────────────────────────────────────────────────────
  → в api.py падает get_user на пустом ответе — найди причину и почини

  ✓ grep      TODO|get_user · 3 совпадения в 2 файлах · 0.1с
  ✓ read      api.py · строки 120—180 · 0.0с
  ⏵ edit      api.py …

  Нашёл: get_user() не проверял ответ на None и падал на user["id"].
  Добавил проверку и тест на пустой ответ.

  ● готово за 12.4с · 3 шага · вх 8.2K · вых 640 · списано 17 680 зачётных
 ╭────────────────────────────────────────────────────────────────────────────╮
 │ >                                                                          │
 ╰── Enter — отправить · Alt+Enter — строка · /help ──────────────────────────…
 ctx 4% │ вх 8.2K │ вых 640 │ ×2 │ день 17K/400K █░░░░░░░░░
```

Панели: лента событий сверху, строка состояния задачи, поле ввода в рамке, внизу —
статус (доля контекста, расход за день, коэффициент модели). Ответ модели печатается
**по мере генерации**, инструменты показываются одной строкой каждая.

## Управление

Задачу пишете словами. Чем конкретнее (файлы, ожидаемое поведение), тем меньше шагов
и токенов. Многострочную задачу собирайте через **Alt+Enter**, путь к файлу подставляйте
через **@** (сработает подсказка), команду дописывайте **Tab**-ом.

| Клавиша | Действие |
|---|---|
| **Enter** | отправить задачу |
| **Alt+Enter**, **Ctrl+J** | перенос строки в задаче |
| **Tab** | дописать команду (`/mod…`) или путь (`@src/…`) |
| **↑ ↓** | история задач (в многострочном вводе — ход по строкам) |
| **PageUp / PageDown** | листать ленту |
| символы во время работы агента | печатаются в строку заранее (typeahead), Enter отправит после окончания |
| **Esc**, **Ctrl+C** | остановить задачу |
| **Ctrl+C** дважды в покое, **Ctrl+D** | выход |
| **Ctrl+Shift+C** / **Ctrl+Shift+V** | копировать (строку ввода или последний ответ) и вставить из буфера; то же — `/copy`, `/paste` |
| **Ctrl+V** | подробный вывод: содержимое результатов инструментов и диффы |
| **Ctrl+L** | перерисовать экран |
| **Ctrl+W / Ctrl+U / Ctrl+K** | стереть слово / до курсора / после курсора |
| **Ctrl+R** | куда уходят токены |

Команды (полный список — `/help`):

| Команда | Что делает |
|---|---|
| `/model` | выбрать модель или маршрут; показывает коэффициент расхода |
| `/tokens` | контекст, кэш, расход за сутки по моделям |
| `/clear` | новая тема: забыть историю и память сессии (дешевле следующий шаг) |
| `/compact` | сжать историю вручную |
| `/diff` | что изменилось в файлах за сессию |
| `/undo` | откатить все правки сессии (созданные файлы удаляются) |
| `/tree` | дерево файлов проекта |
| `/session` | что агент помнит о прошлых задачах |
| `/steps 12` | лимит шагов на задачу |
| `/limit 600000` | дневной лимит зачётных токенов (`0` — снять) |
| `/confirm` | режим правок: `ask` · `auto` · `readonly` |
| `/verbose` | подробный вывод инструментов |
| `/theme` | тема: `rose` (по умолчанию) · `dark` · `night` · `light` · `mono` |
| `/cd` | сменить рабочую папку |
| `/prompt spec.md` | большой промт из файла — прямо в строку ввода |
| `/copy` · `/paste` | копировать ответ/строку и вставить из буфера |
| `/api` | загрузить ключ: диалог, `/api sk-smart-…` или `/api ключ.txt` (`/key` — синоним) |
| `/doctor` | диагностика: ключ, шлюз, модели, лимиты |
| `/models reload` | подтянуть список моделей шлюза |
| `/router` | поднять шлюз для редакторов (остановить — `/router stop`) |
| `/exit` | выход |

## Модели и маршруты

Баланс SmartAPI списывает **зачётные токены** = токены × коэффициент модели. ELYTRIX
считает расход ровно так же и показывает его после каждого шага.

| Маршрут | Модель | × | Когда |
|---|---|---|---|
| `auto` | claude-sonnet-4-6 | 2 | обычная работа — обычно хватает |
| `cheap` | gpt-5.6-luna | 1.7 | мелкие правки и вопросы |
| `smart` | claude-opus-4-8 | 4 | сложные задачи |
| `max` | claude-opus-5 | 5 | тяжёлое, где важна каждая попытка |

Полный каталог с коэффициентами: `python app/run.py --models` или `/model` в консоли.
Свою модель можно назвать прямо в `/model gpt-6-astra` — даже если её нет в каталоге,
расход будет считаться как ×1, а `/models reload` добавит её в список.

## Почему это дёшево и быстро

| Приём | Что даёт |
|---|---|
| **Прямое соединение** | нет локального HTTP-хопа: агент — один процесс, один keep-alive канал до шлюза (−100…300 мс на TLS-рукопожатие за запрос) |
| **Prompt caching** | системный промпт, инструменты и хвост истории помечаются `cache_control`; повторные шаги читаются из кэша, а не считаются заново. Если шлюз кэш не поддержал — метки отключаются сами (по коду 400) |
| **Сжатие истории** | три ступени без платного запроса к модели: результаты инструментов заменяются пометками, содержимое записанных файлов — ссылкой на диск, затем середина истории сворачивается в конспект. Автосжатие — на 55 % контекста |
| **Память сессии** | две строки на задачу вместо всей переписки: «а теперь то же во втором файле» понимается без пересылки истории |
| **Параллельные инструменты** | чтения и поиск из одного ответа модели выполняются вместе — меньше кругов до ответа |
| **Бюджет вывода** | результат инструмента обрезается до 6 000 символов, `grep` — до 40 совпадений, `read` — до 12 000 символов: в историю не попадают мегабайты |
| **Компактные схемы** | 6 инструментов с короткими русскими описаниями — ~400 токенов на весь набор |
| **Дневной лимит** | проверяется **до** запроса: 400 000 зачётных токенов в сутки ≈ 20 дней работы на балансе 8 млн |
| **Стриминг** | ответ виден сразу, отмена (Esc) обрывает запрос, а не ждёт его окончания |
| **Failover** | Anthropic-формат основной, OpenAI-формат запасной; 429 — охлаждение, 5xx — повтор, обрыв потока — повтор |

## Инструменты агента

`ls` · `read` · `grep` · `write` · `edit` · `bash` — шесть штук, и этого хватает.
Все файловые операции заперты в рабочей папке, `bash` не пускает разрушительные команды
(`rm -rf /`, `sudo rm`, `curl … | sh`), а каждая правка сначала попадает в резервную
копию: `/diff` показывает изменения сессии, `/undo` возвращает всё как было
(созданные агентом файлы удаляются).

Режимы правок: `ask` — спрашивать на каждую (показывает дифф), `auto` — править сразу,
`readonly` — только чтение. Переключается `/confirm` или флагами `-y` / `--ask` /
`--readonly`.

## Из командной строки

```bash
python app/run.py                                  # полноэкранная консоль
python app/run.py "в api.py исправь get_user"       # одна задача и выход
python app/run.py "прогони тесты" --plain           # то же без полноэкранного режима
python app/run.py -w D:\code\my-project -m cheap    # своя папка и дешёвая модель
python app/run.py --doctor                          # диагностика: ключ, шлюз, лимиты
python app/run.py --models                          # каталог моделей с коэффициентами
python app/run.py --router 8789                     # только шлюз для редакторов
ELYTRIX-ROUTER.bat                                  # то же двойным кликом (Windows)
```

Если вывод не в терминал (файл, CI, конвейер сборки) — агент сам переключается в обычный режим:
поток текста, по строке на инструмент, итог с расходом.

## Настройки

`config/elytrix.json` — правится блокнотом, подхватывается при следующем запуске.
Ключ в нём **не хранится**. Что меняют чаще всего:

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `models.default` | `auto` | с какой модели начинать |
| `limits.daily_tokens` | `400000` | дневной предохранитель (`0` — снять) |
| `limits.max_steps` | `24` | потолок шагов на задачу |
| `economy.compact_at` | `0.55` | доля контекста, после которой история сжимается сама |
| `economy.cache` | `true` | промпт-кэш |
| `ui.confirm` | `ask` | режим правок |
| `ui.theme` | `rose` | оформление: розово-белая по умолчанию |
| `router.port` | `8789` | порт шлюза для редакторов |

Настройки отдельного проекта кладутся в `<папка проекта>/.elytrix/config.json` и
перекрывают общие. Профиль пользователя (ключ, расход, последняя папка, тема) — в
`~/.elytrix/`.

## Редакторы: Cline, Continue, opencode, Cursor

Консоли роутер не нужен, а редакторам нужен HTTP-адрес. Поднимите его (`/router`
внутри консоли или `ELYTRIX-ROUTER.bat`) и укажите в редакторе:

```
Base URL:  http://127.0.0.1:8789/v1
API key:   любой (например elytrix) — настоящий ключ роутер держит у себя
Model:     auto | cheap | smart | max | любая модель из /v1/models
```

Поддержаны `POST /v1/chat/completions` (OpenAI, со стримингом), `POST /v1/messages`
(Anthropic, со стримингом), `GET /v1/models`, `GET /status.json`, `GET /health`.
Расход идёт через тот же учёт: коэффициенты, дневной лимит, кэш. Подробности и готовые
фрагменты конфигов — [docs/04-РЕДАКТОРЫ-И-РОУТЕР.md](docs/04-РЕДАКТОРЫ-И-РОУТЕР.md).

## Тесты

подменяется локальным `dev/tests/mockapi.py`, который умеет стриминг, ошибки, обрыв

python dev/tests/run_all.py            # всё (~2.5 минуты)

## Требования и границы

- Python 3.8+ (проверено на 3.11), только стандартная библиотека.
- Windows 10+, Linux, macOS. В Windows нужен терминал с поддержкой VT — `conhost`
  Windows 10 и Windows Terminal подходят; агент включает VT-режим сам.
- Если Unicode недоступен (старая кодовая страница), рамки и значки автоматически
  заменяются на ASCII — интерфейс остаётся читаемым.
- Агент не хранит ключ в файлах проекта и не отправляет его никуда, кроме шлюза SmartAPI.
