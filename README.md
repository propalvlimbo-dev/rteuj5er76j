# FreeCoder — ИИ-агент на вашем ключе SmartAPI

Агент читает ваши файлы и **сам их правит**: пишет сайт, дописывает код, откатывает неудачные
правки. Работает на купленном балансе SmartAPI — один ключ `sk-smart-…`, один шлюз,
никакой ротации и десятка регистраций.

```
   агент FreeCoder / opencode / Cline / Continue / Claude Code
                    │
                    ▼
      FreeCoder Router  127.0.0.1:8788           ← дневной лимит расхода,
      (ваш компьютер)                              учёт коэффициентов по моделям
                    │
                    ▼
      https://api.smartapi.shop                  ← ваш баланс 8 000 000
```

Роутер между агентом и шлюзом нужен ради трёх вещей: **дневной лимит** (баланс тратится
ровно, а не сгорает за вечер), **учёт коэффициентов** (каждая модель считается по своему
множителю: Luna ×1,7, Sonnet ×2, Opus ×4, Fable ×10) и **два адреса шлюза** — если один
формат не отвечает, запрос уйдёт во второй.

## Запуск: три шага

**1. Python 3.8+** — проверка в командной строке: `python --version`.
Нет — поставить с <https://www.python.org/downloads/> с галочкой **Add Python to PATH**.

**2. Ключ** — кабинет <https://smartapi.shop/api-keys>, создать `sk-smart-…`.

**3. Двойной клик:**

```
START.bat
```

Спросит ключ (один раз), поднимет роутер, покажет модели и **спросит папку с вашим кодом** —
туда и будет работать агент. Папка запоминается, в следующий раз достаточно Enter.

Всё происходит в **одном окне**: и агент, и роутер. Каждый шаг — одна строка:

```
  [1/15] пишу index.html (247 символов) · 0.0с · вход 2.0K / выход 220 · сегодня 4.5K/400K
       Файл создан: index.html (247 символов)
  [2/15] пишу style.css (216 символов) · 0.0с · вход 2.2K / выход 220 · сегодня 4.5K/400K

✅ Собрал мини-сайт: index.html, style.css, app.js
   файлы: app.js, index.html, style.css
   шагов: 4 из 15 · токенов: вход 9.0K, выход 880 · сегодня 4.5K/400K
```

**вход** — это история, которую модель читает заново на каждом шаге (главная статья расхода),
**выход** — то, что она написала. `сегодня` — расход из дневного лимита.

Правки применяются **сразу** — на каждую не надо жать `y`. Откат: `/undo`.
Хотите подтверждать каждую — `/confirm on`.

**4. Работа:** пишете задачи словами в окне агента.

```
в api.py функция get_user падает, если ответ пустой — сделай проверку и верни None
добавь в index.html секцию с ценами: три тарифа, средний выделен
добавь тесты для parse_date (пустой ввод, кривой формат)
```

Агент **помнит, что вы писали раньше в этой сессии**: после каждой задачи в память
попадает по две короткие строки — что попросили и что сделали. Поэтому «добавь ещё кнопку»
и «поменяй цвет на синий» работают как продолжение, а не как новая задача с нуля.
Посмотреть память — `/history`, забыть — `/clear` (это же и самый дешёвый режим).

Команды по ходу работы:

| Команда | Что делает |
|---|---|
| `/model` | меню моделей: Claude, **GPT**, Codex — каждая с коэффициентом расхода |
| `/tokens` | разбор расхода: сколько уйдёт на следующий шаг и что именно занимает место |
| `/history` | что агент помнит о прошлых задачах этой сессии |
| `/clear` | забыть прошлые задачи (новая тема — дешевле) |
| `/steps 8` | сколько шагов разрешено на задачу (по умолчанию 15) |
| `/diff`, `/undo` | что изменилось, откатить правки |
| `/confirm on\|off` | спрашивать подтверждение на каждую правку или применять сразу |

Больше ничего ставить не нужно: ни Node.js, ни Git, ни VS Code. Зависимостей у проекта нет
вообще — только стандартная библиотека Python.

## Структура: что где лежит

```
START.bat            ← запуск одним кликом (ключ → роутер → модель → папка → агент)
START-ROUTER.bat     ← только роутер в своём окне: для VS Code (Cline/Continue), opencode
install.ps1          ← необязательный установщик программ (Python, Node — по желанию)
README.md

app/                 ← вся программа
  launch.py            сценарий запуска (что делает START.bat)
  agent.py             агент: читает, ищет, правит файлы, откатывает, считает расход
  router.py            шлюз: дневной лимит, коэффициенты моделей, два адреса SmartAPI
  check_key.py         проверка купленного доступа и список моделей шлюза

config/              ← настройки
  providers.json       адреса SmartAPI, модели, коэффициенты, дневной лимит tpd
  opencode.json        конфиг opencode
  continue.yaml        конфиг Continue для VS Code

docs/                ← инструкции (список ниже)
dev/                 ← служебное, руками трогать не нужно
  tests/               156 автотестов
  inspect_npm_package.py  разбор чужого npm-пакета до установки
```

Агент и роутер работают и на macOS/Linux:

```
python3 app/launch.py            # запуск как START.bat
python3 app/router.py --config config/providers.json
```

## Ваш баланс: как не сжечь

`8 000 000` — это **зачётные** токены, списание идёт с коэффициентом модели:

| Модель | Коэф. | Токенов работы | Кому |
|---|---|---|---|
| **gpt-5.6-luna** | **×1,7** | 4,7 млн | самая дешёвая: мелкие правки, вопросы по коду |
| **claude-sonnet-4-6** | **×2** | 4,0 млн | рабочая лошадка (по умолчанию, маршрут `auto`) |
| claude-sonnet-5 | ×2,5 | 3,2 млн | чуть умнее, чуть дороже |
| gpt-5.6-terra | ×3 | 2,7 млн | середина |
| claude-opus-4-6 / 4-7 / 4-8, gpt-5.6-sol, codex-auto-review | ×4 | 2,0 млн | сложные задачи (`smart`) |
| claude-opus-5 | ×5 | 1,6 млн | максимум качества (`max`) |
| gpt-6-astra | ×8 | 1,0 млн | для тяжёлого |
| claude-fable-5 / 5.1 | ×10 | 0,8 млн | только по необходимости |

> **Правило: обычная работа — `auto` (Sonnet) или `cheap` (Luna ×1,7); `smart` и `max` — по делу;
> Fable и Astra — не трогать без нужды.**

В конфиге уже стоит дневной лимит `tpd: 400000` — после его выбора роутер до конца суток
сам перестаёт обращаться к платному каналу. Это превращает «8 млн за один вечер» в
«примерно 20 дней спокойной работы». Хотите быстрее или медленнее — одно
число в `config/providers.json`.

Что уже сделано против лишнего расхода: история сжимается (старые файлы не пересылаются
заново), чтение файла ограничено 8000 символов, шагов на задачу — 15, а расход виден
в каждой строке. Замеры и приёмы: `docs/08-ЭКОНОМИЯ-ТОКЕНОВ.md`.

## Три способа работать

| Способ | Как | Кому |
|---|---|---|
| **Свой агент** (русскоязычный, ничего не ставит) | `START.bat` | правка своего кода и создание нового |
| **opencode** — терминальный TUI | `START-ROUTER.bat` + `config/opencode.json` | привыкшим к терминальным агентам |
| **VS Code:** Cline / Kilo Code / Continue | `START-ROUTER.bat` + `docs/03-ПОДКЛЮЧЕНИЕ-ПРИЛОЖЕНИЙ.md` | тем, кто хочет видеть diff в редакторе |
| **Claude Code** | `docs/03`, раздел «напрямую» | если уже им пользуетесь |

Все они ходят в один роутер — поэтому дневной лимит общий, а расход виден в строке каждого
запроса. Для редакторов роутер запускается отдельным окном: `START-ROUTER.bat`.

## Как это устроено внутри (и почему так дешевле)

* **Память сессии.** Агент помнит тезисы прошлых задач («что просили» + «что сделали» +
  изменённые файлы) — это несколько сотен символов на задачу, а не вся переписка.
* **Один шаг — один инструмент.** Агент не «думает вслух» простынями: одна строка «что делаю»,
  одна строка результата. Промежуточные JSON-дампы пользователю не показываются.
* **История сжимается на каждом шаге.** Записанный файл больше не пересылается целиком —
  вместо него пометка «N символов убрано из контекста: файл уже на диске». Это главный
  источник экономии: цена задачи растёт как «шаги × размер истории».
* **Правка вместо перезаписи.** Для существующих файлов агент меняет фрагмент
  (`replace_in_file`), а не переписывает файл целиком.
* **Резервные копии в `.freecoder/`** внутри рабочей папки: `/diff` и `/undo` в любой момент.
* **Свой шлюз-роутер** держит дневной лимит и умеет уходить на второй адрес SmartAPI.

Про то, как это устроено у других CLI-агентов (Aider, OpenCode, OpenHands, Codex CLI,
Gemini CLI) и что мы оттуда взяли, — `docs/09-КАК-РАБОТАЮТ-ДРУГИЕ-АГЕНТЫ.md`.

## Честно о том, что вы купили

* **Это не безлимит.** 8 млн зачётных токенов — это примерно 15–30 рабочих сессий на Sonnet,
  а не «навсегда». Расход виден в строке каждого шага и в кабинете шлюза.
* **Баланс может закончиться не по вашей вине.** Продажа доступа с чужого аккаунта живёт
  до бана или до конца чужого баланса. Держите в голове, что доступ может отключиться в любой день.
* **Шлюз видит ваши запросы.** Не отправляйте через него код под NDA, `.env`, пароли и
  персональные данные.
* **Не запускайте чужие установщики** («настрою всё за минуту»). Всё, что они делают, вы уже
  сделали руками и видите у себя в конфигах: `docs/05-БЕЗОПАСНОСТЬ.md`.
