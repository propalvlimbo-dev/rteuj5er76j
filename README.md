# FreeCoder — ИИ-агент, который сам правит ваши файлы

**Бесплатный аналог Cursor/Claude Code:** агент читает ваш проект, сам вносит правки,
запускает тесты и продолжает работу даже когда бесплатные лимиты у одного провайдера
закончились — потому что у вас не один провайдер, а шесть плюс локальная модель.

```
   ваш терминал / VS Code / opencode
                │
                ▼
   ┌──────────────────────────────────────────┐
   │  FreeCoder Router  (127.0.0.1:8788)      │   ← один «бесконечный» API
   │  • выбирает провайдера с живой квотой    │
   │  • ловит 429 и переводит на следующего   │
   │  • ротирует несколько ключей             │
   │  • когда всё кончилось → локальная Ollama│
   └───┬──────┬───────┬───────┬───────┬───────┘
       │      │       │       │       │
   Gemini  Groq   Mistral  OpenRouter  NVIDIA/GLM  →  Ollama (ваш ПК)
   (free)  (free)  (free)    (free)      (free)          без лимитов
```

---

## Честно: что такое «бесплатно и бесконечно»

Бесконечного бесплатного GPT-5/Claude Opus не существует — за видеокарты кто-то платит.
Но практическая бесконечность делается так:

| Что даёт | Кто даёт | Реальный лимит (сен 2026) |
|---|---|---|
| Качество почти как у топов | Google AI Studio (Gemini Flash) | ~10 запросов/мин, дневная квота падает в полночь по UTC |
| Очень быстро | Groq (gpt-oss-120b / qwen3.6-27b) | 30/мин, 1000/день, **200k токенов/день** ← узкое место |
| Самый большой объём | Mistral Experiment (Codestral, Devstral) | ~1 млрд токенов/месяц, 1 запрос/сек |
| Много моделей одним ключом | OpenRouter (`:free`) | 50/день, а после разовой покупки $10 → **1000/день навсегда** |
| Подстраховка | NVIDIA NIM, Z.ai GLM Flash | 40/мин и т.д. |
| **По-настоящему без лимитов** | **Ollama на вашем ПК** | нет лимитов, нет интернета, нет счетов |

Роутер из этого репозитория складывает всё вместе и **переключает автоматически**.
В типичный день вы просто работаете; когда Gemini остывает — отвечает Groq, когда и он
выработал 200k токенов — Mistral, потом OpenRouter… а если ночью всё исчерпано —
локальная модель продолжает править код без всяких квот.

> Дополнительно: одна разовая покупка кредитов OpenRouter на **$10** навсегда поднимает
> лимит со 50 до 1000 запросов/день. Это единственные деньги во всей схеме, и они не обязательны.

## Установка за 4 шага (Windows 10/11)

```powershell
# 1. Распакуйте папку с проектом и откройте PowerShell в ней
cd путь\к\папке

# 2. Установщик: Git + Python + Node + Ollama + opencode, разложит конфиги
powershell -ExecutionPolicy Bypass -File windows\install.ps1

# 3. В открывшемся Блокноте вставьте бесплатные ключи (как их взять — docs\02-КЛЮЧИ-БЕСПЛАТНО.md)
#    Начать можно вообще с одного ключа Gemini.

# 4. Запустите роутер (окно оставить открытым) и агента
windows\START-ROUTER.bat
windows\START-AGENT.bat   "добавь в телеграм-бота команду /help"
```

Агент покажет, что собирается изменить, спросит подтверждение и применит правку.
Откатить всё одной командой: `/undo` в диалоге агента.

**Проверка без ключей вообще:** запустите `START-ROUTER.bat` с добавленным `--mock`
(дописывается в конец строки с `python`), и агент заработает на заглушке — так видно,
что вся связка жива.

## Три способа работать с агентом

| Способ | Как | Кому |
|---|---|---|
| **Свой агент** `agent/freecoder_agent.py` | `START-AGENT.bat "задача"` | тем, кто хочет простой русскоязычный агент без установки тяжёлых инструментов |
| **opencode** (терминальный TUI, 200k★ на GitHub) | `START-OPENCODE.bat` | привыкшим к TUI; модель уже настроена на роутер |
| **VS Code**: Cline / Kilo Code / Continue | `vscode/README.md` | тем, кто хочет видеть правки и diff в редакторе |

Все три ходят в один и тот же роутер, поэтому делят лимиты и видны в одной панели:
**http://127.0.0.1:8788/** — кто сколько квоты съел, кто остывает и на сколько.

## Что внутри репозитория

```
router/freecoder_router.py     шлюз: ротация, failover, учёт лимитов, стриминг   (stdlib, без зависимостей)
router/providers.example.json  список бесплатных провайдеров и моделей
agent/freecoder_agent.py       сам агент: читает, ищет, правит файлы, гоняет команды
opencode/opencode.json         конфиг терминального агента opencode под роутер
vscode/continue-config.yaml    конфиг Continue для VS Code
windows/install.ps1            установщик для Windows
windows/START-*.bat            запуск в один клик
tools/check_api_key.py         проверяльщик чужих ключей: подмена модели, лимиты, вранье в токенах
tests/                         49 тестов: failover, ротация ключей, откат, защита от опасных,
                               детекторы проверяльщика (поднимаем фальшивые шлюзы с «грехами»)
docs/                          подробные инструкции и «правда о бесплатном»
```

Зависимостей нет вообще: только стандартная библиотека Python 3.8+. Роутер и агент
работают и на macOS/Linux (`python3 router/freecoder_router.py`).

## Безопасность: агент правит файлы, поэтому

* все действия **ограничены рабочей папкой** — путь наружу запрещён (есть тест);
* перед каждой правкой показывается **diff**, применяется только после подтверждения;
* **резервные копии** всех изменённых файлов + `/undo` и `/diff` в любой момент;
* разрушительные команды (`rm -rf /`, `format`, `curl | sh`, `npm publish` …) заблокированы;
* `--dry-run` — режим «покажи, что сделал бы, но не трогай»;
* секреты (`.env`, ключи) агент не читает без прямой просьбы.

Подробнее — `docs/04-БЕЗОПАСНОСТЬ.md`.

## Что честно сказать про качество

* Бесплатные модели **сильно различаются по силе**: Gemini Flash и North Mini Code тянут
  многошаговые правки хорошо; gpt-oss-20b / Gemma — нормально для простых задач;
  локальная 7B — для мелких правок и офлайна.
* Бесплатные тарифы **меняются каждую неделю**. Роутер к этому устойчив: он не «знает»
  про лимиты, он их соблюдает и обходит; список моделей в `providers.json` можно править руками.
* Лимиты **на одного человека и один аккаунт**. Регистрировать 10 аккаунтов, чтобы обойти
  квоту — против правил сервисов (и они это ловят). Правильный путь: много *разных*
  сервисов, как в этом репозитории, плюс локальная модель.
