# FreeCoder — ИИ-агент на вашем ключе SmartAPI

Агент читает ваши файлы и **сам их правит**: пишет сайт, дописывает код, откатывает неудачные
правки. Работает на купленном балансе SmartAPI — один ключ `sk-smart-…`, один шлюз,
никакой ротации и десятка регистраций.

```
   agent / opencode / Cline / Kilo / Claude Code
                    │
                    ▼
      FreeCoder Router  127.0.0.1:8788            ← дневной лимит расхода,
      (ваш компьютер)                                учёт коэффициентов, резерв
                    │
                    ▼
      https://api.smartapi.shop                   ← ваш баланс 8 000 000
```

Роутер между агентом и шлюзом нужен ради трёх вещей: **дневной лимит** (баланс тратится
ровно, а не сгорает за вечер), **учёт коэффициентов** (видно, сколько зачётных токенов ушло)
и **резерв** — если ключ откажет или шлюз отвалится, работа продолжится на бесплатных моделях
и локальной Ollama.

---

## Запуск: четыре шага

**1. Python 3.8+** — проверка в командной строке: `python --version`.
Нет — поставить с <https://www.python.org/downloads/> с галочкой **Add Python to PATH**.

**2. Ключ** — кабинет <https://smartapi.shop/api-keys>, создать `sk-smart-…`.

**3. Двойной клик:**

```
windows\START-SMARTAPI.bat
```

Спросит ключ (один раз), поднимет роутер, откроет панель расхода, создаст папку сайта и
запустит агента, который сам напишет первую версию сайта.

**4. Результат:**

```
двойной клик → C:\Users\<вы>\site\index.html
```

Дальше правки пишутся словами в окне агента: «добавь меню сверху», «сделай блок с ценами».
`/diff` — что изменилось, `/undo` — откат, `/model smart` — Opus для сложной задачи, `/exit` — выход.

Больше ничего ставить не нужно: ни Node.js, ни Git, ни VS Code. Зависимостей у проекта нет
вообще — только стандартная библиотека Python.

## Ваш баланс: как не сжечь

`8 000 000` — это **зачётные** токены, списание идёт с коэффициентом модели:

| Модель | Коэф. | Токенов работы | Сессий агента |
|---|---|---|---|
| Haiku 4.5 | ×1 | 8 000 000 | 40–80 |
| **Sonnet 4.6** | **×2** | **4 000 000** | **15–30** |
| Opus 4.6 / 4.7 / 4.8 | ×4 | 2 000 000 | 8–15 |
| Opus 5 | ×5 | 1 600 000 | 6–12 |
| Fable 5 / 5.1 | ×10 | 800 000 | 3–5 |

> **Правило: работа — Sonnet 4.6, Opus 4.8 — только по команде `/model smart`, Fable 5 — не трогать.**

В конфиге уже стоит дневной лимит `tpd: 400000` — после его выбора роутер до конца суток
сам уходит на бесплатные модели. Это превращает «8 млн за один вечер» в «примерно 20 дней
спокойной работы». Хотите быстрее или медленнее — одно число в
`router/providers.smartapi.json`.

Подробно: `docs/02-КЛЮЧ-БАЛАНС-ЛИМИТЫ.md`.

## Три способа работать

| Способ | Как | Кому |
|---|---|---|
| **Свой агент** (русскоязычный, ничего не ставит) | `windows\START-AGENT.bat "задача"` | быстрый старт, работа с текстом и файлами |
| **opencode** — терминальный TUI | `windows\START-OPENCODE.bat` | привыкшим к терминальным агентам |
| **VS Code:** Cline / Kilo Code / Continue | `docs/03-ПОДКЛЮЧЕНИЕ-ПРИЛОЖЕНИЙ.md` | тем, кто хочет видеть diff в редакторе |
| **Claude Code** | `docs/03`, раздел «напрямую» | если уже им пользуетесь |

Все они могут ходить в один роутер — тогда расход виден в одной панели
(<http://127.0.0.1:8788/>) и дневной лимит общий.

## Что внутри репозитория

```
router/freecoder_router.py       шлюз: лимиты, коэффициенты, failover, стриминг, панель
router/providers.smartapi.json   рабочий конфиг: SmartAPI + бесплатный резерв + Ollama
agent/freecoder_agent.py         агент: читает, ищет, правит файлы, откатывает, гоняет команды
opencode/opencode.json           конфиг opencode под роутер
vscode/continue-config.yaml      конфиг Continue для VS Code
windows/START-SMARTAPI.bat       один клик: ключ → роутер → папка сайта → агент
windows/START-ROUTER.bat         только роутер (уже сам берёт smartapi-конфиг, если есть ключ)
windows/START-AGENT.bat          только агент
windows/install.ps1              установщик: Python, Node, Ollama, opencode (не обязателен)
tools/check_api_key.py           проверка купленного доступа (форматы OpenAI и Anthropic)
tools/inspect_npm_package.py     разбор чужого npm-пакета до установки
tests/                           73 теста: failover, лимиты, откат, защита файлов,
                                 перевод OpenAI↔Anthropic, детекторы проверяльщика
docs/                            инструкции (см. таблицу ниже)
docs/архив/                      старая схема «много бесплатных ключей» — на случай,
                                 если баланс закончился и покупать пока не хочется
```

Роутер и агент работают и на macOS/Linux: `python3 router/freecoder_router.py`.

## Честно о том, что вы купили

* **Это не безлимит.** 8 млн зачётных токенов — это примерно 15–30 рабочих сессий на Sonnet,
  а не «навсегда». Расход виден в панели и в кабинете шлюза.
* **Баланс может закончиться не по вашей вине.** Продажа доступа с чужого аккаунта живёт
  до бана или до конца чужого баланса. Поэтому в конфиге включён резерв: бесплатные модели
  и локальная Ollama подхватят работу, когда ключ умрёт.
* **Шлюз видит ваши запросы.** Не отправляйте через него код под NDA, `.env`, пароли и
  персональные данные — для такого есть `/model local`.
* **Не запускайте чужие установщики** («настрою всё за минуту»). Всё, что они делают, вы уже
  сделали руками и видите у себя в конфигах: `docs/05-БЕЗОПАСНОСТЬ.md`.
