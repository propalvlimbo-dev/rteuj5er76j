# Лимиты, арифметика «бесконечности» и выбор моделей

Данные на **сентябрь 2026**. Бесплатные тарифы меняются часто — роутер к этому устойчив
(он ловит 429 и уходит дальше), но цифры стоит перепроверять в кабинетах провайдеров.

## 2. Почему нужен именно роутер (арифметика)

Типичный рабочий день агента — это 150–400 запросов и 1–3 млн токенов: агент на каждом
шаге заново отправляет контекст (системный промпт, дерево проекта, прочитанные файлы,
результаты команд).

| Сценарий | Сколько хватит |
|---|---|
| Только Groq | ~1 час работы: 200k токенов/день — это 5–8 «тяжёлых» шагов |
| Только Gemini Flash | хороший день работы, если не гонять агента непрерывно |
| Только OpenRouter free | 50 запросов/день — это одна небольшая задача |
| Gemini + Groq + Mistral + OpenRouter + NVIDIA + GLM | **практически непрерывный день**, роутер переключает молча |
| Всё выше + локальная Ollama | **непрерывно и без потолка** — последний рубеж не имеет лимитов |

Именно поэтому «бесконечность» — это не одна бесплатная модель, а **цепочка** моделей,
склеенная роутером. Плюс разовые $10 на OpenRouter превращают 50 в 1000 запросов/день
и снимают большую часть проблем.

## 3. Какая модель что тянет

| Задача | Кто справится |
|---|---|
| Многофайловые правки, рефакторинг, «прочитай проект и почини» | Gemini Flash, Cohere North Mini Code, Qwen3-Coder 480B, Poolside Laguna M.1 |
| Обычные правки, тесты, документация | gpt-oss-120b (Groq/NVIDIA), Codestral, GLM Flash |
| Быстрые мелкие правки, автодополнение | gpt-oss-20b на Groq, Flash-Lite, ministral |
| Работа офлайн / приватный код | локальные: qwen2.5-coder:7b, gpt-oss:20b |
| Сложная архитектура, длинные цепочки рассуждений | Gemini Flash (лучшее из бесплатного) |

Практика: держите `/model smart` для задач «подумать» и `/model fast` для мелочей —
так экономится квота сильных моделей.

## 4. Локальные модели под 16 ГБ RAM (без видеокарты)

| Модель | Размер | Как идёт | Для чего |
|---|---|---|---|
| `qwen2.5-coder:7b` | ~4.7 ГБ | комфортно, ~5–10 ток/сек | правки в файлах, простые функции, офлайн-режим |
| `qwen2.5-coder:14b` | ~9 ГБ | терпимо, ~2–4 ток/сек | более сложные правки, если готовы ждать |
| `gpt-oss:20b` | ~13 ГБ | тяжело, только при 16 ГБ и без других программ | рассуждения, но медленно |
| `qwen2.5-coder:1.5b` | ~1 ГБ | очень быстро | автодополнение, черновые подсказки |

```powershell
ollama pull qwen2.5-coder:7b       # основная рабочая
ollama pull qwen2.5-coder:1.5b     # для скорости
```

Модель по умолчанию для провайдера `ollama` задаётся в `router\providers.json`
(поле `models`). Если скачали 14b — поставьте её первой в списке.

## 5. Настройка роутера под себя

`router\providers.json`:

```json
{
  "default_alias": "auto",
  "prefer_local_when_quota_out": true,
  "aliases": {
    "smart": ["google/gemini-3.8-flash", "openrouter/cohere/north-mini-code:free", "groq/openai/gpt-oss-120b"]
  }
}
```

* **`aliases`** — свои маршруты. Порядок = приоритет: первый живой и получает запрос.
* **`prefer_local_when_quota_out: true`** — когда все облака исчерпаны, не отказывать,
  а молча уходить на Ollama.
* **`limits`** у провайдера — можно поставить свои, если провайдер изменил квоты.
* **`cooldown_on_429`** — сколько секунд не трогать ключ после отказа (по умолчанию 900).

## 6. Что делать, если хочется «сильнее, чем бесплатно»

| Вариант | Цена | Что получаете |
|---|---|---|
| Разовые $10 на OpenRouter | один раз | 1000 бесплатных запросов/день навсегда |
| Mistral Experiment | бесплатно (телефон) | ~1 млрд токенов/мес — самый щедрый лимит на рынке |
| Локальная модель на 32B + GPU 24 ГБ | железо | полная приватность и никаких лимитов |
| Платный ключ любого провайдера | от нескольких $/мес | просто добавьте его в тот же `providers.json` как ещё одного провайдера — роутер подхватит |

Архитектура специально сделана так, чтобы платный провайдер добавлялся одной строкой
в конфиг — и использовался только тогда, когда бесплатные кончились (поставьте ему
приоритет 5, а бесплатным — 10+).
