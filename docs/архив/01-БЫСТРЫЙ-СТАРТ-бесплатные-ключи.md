# Быстрый старт (Windows 10/11)

Полный путь: от пустой системы до агента, который сам правит ваши файлы. ~15 минут,
из них 10 — скачивание программ и локальной модели.

---

## Шаг 0. Что понадобится

* Windows 10/11, 16 ГБ RAM — комфортно (у вас как раз столько).
* Интернет для установки и для облачных бесплатных моделей.
* Права обычного пользователя. Админ нужен только для установки программ через `winget`.

---

## Шаг 1. Распаковать проект и запустить установщик

1. Распакуйте папку проекта, например в `C:\FreeCoder`.
2. Откройте **PowerShell** в этой папке: в Проводнике `Shift` + правый клик → «Открыть окно PowerShell здесь».
3. Выполните:

```powershell
powershell -ExecutionPolicy Bypass -File windows\install.ps1
```

Установщик сделает:
* поставит через `winget`: **Git**, **Python 3.12**, **Node.js LTS**, **Ollama**;
* поставит терминальные агенты: **opencode** и **Gemini CLI**;
* создаст `router\providers.json` и откроет его в Блокноте — туда вставляются ключи;
* положит конфиги: `%USERPROFILE%\.config\opencode\opencode.json` и `%USERPROFILE%\.continue\config.yaml`;
* скачает локальную модель `qwen2.5-coder:7b` (~5 ГБ).

Если установщик предупредит, что программы «не найдены в PATH» — закройте окно,
откройте новое и запустите:

```powershell
powershell -ExecutionPolicy Bypass -File windows\install.ps1 -SkipWinget
```

---

## Шаг 2. Вставить бесплатные ключи

В открывшемся Блокноте (это `router\providers.json`) найдите блоки вида:

```json
{ "name": "google", "key_env": "GEMINI_API_KEY", "keys": [] }
```

и впишите ключ в квадратные скобки: `"keys": ["AIza..."]`.

Минимум — один ключ Google (шаги: `docs\архив\02-КЛЮЧИ-БЕСПЛАТНО.md`, раздел 1).
Максимум — все шесть сервисов: тогда лимиты почти не заканчиваются.

> Блокнот откроет файл без подсветки — это нормально. Главное не сломать кавычки и запятые.

Сохраните (`Ctrl+S`) и закройте.

---

## Шаг 3. Запустить роутер

Двойной клик: **`windows\START-ROUTER.bat`**

Появится окно с надписью:

```
FreeCoder Router v1.0.0 слушает http://127.0.0.1:8788
  панель:  http://127.0.0.1:8788/
```

**Это окно не закрывайте** — оно и есть ваш «бесконечный» API.

Откройте <http://127.0.0.1:8788/> — там видно: сколько запросов съедено, у кого
осталась квота, кто «остывает» после 429. Это ваш главный прибор наблюдения.

---

## Шаг 4. Работать с агентом

### Вариант А — свой агент (проще всего)

```powershell
windows\START-AGENT.bat "добавь в telegram_bot.py команду /help с описанием"
```

или просто `windows\START-AGENT.bat` — и пишите задачи по-русски в диалоге.

Другие проекты:

```powershell
windows\START-AGENT.bat C:\Projects\мой_сайт
```

Примеры задач, которые он умеет:
* «исправь ошибку — при пустом ответе API падает с TypeError»
* «добавь тесты pytest для функций из utils.py»
* «перепиши README под текущий код»
* «найди, где захардкожен путь C:\temp, и вынеси в конфиг»

### Вариант Б — opencode (красивый терминальный интерфейс)

Двойной клик: **`windows\START-OPENCODE.bat`**

Модель уже настроена на `freecoder/smart`. Команды: `Tab` — переключение режима,
`/models` — выбор модели, `/help`.

### Вариант В — VS Code

См. `vscode\README.md`: ставите расширение **Cline** или **Kilo Code**, выбираете
провайдер «OpenAI Compatible», Base URL `http://127.0.0.1:8788/v1`, ключ `freecoder`,
модель `smart`. Правки видны как diff прямо в редакторе.

## Управление в агенте

| Команда | Что делает |
|---|---|
| `/help` | справка |
| `/tree` | дерево файлов проекта |
| `/diff` | что агент уже изменил в этой сессии |
| `/undo` | **откатить все правки сессии** |
| `/model smart` | сменить маршрут моделей |
| `/yes` | отключить подтверждения (быстро, но осторожно) |
| `/exit` | выход |

Флаги запуска: `--dry-run` (ничего не менять), `--yes` (не спрашивать),
`--model local` (только локальная модель — без интернета), `--steps 50` (больше шагов).

## Проверка «а работает ли вообще» — без единого ключа

Добавьте `--mock` в конец строки запуска роутера. Проще всего — вручную:

```powershell
python router\freecoder_router.py --mock
```

и в другом окне:

```powershell
python agent\freecoder_agent.py --workspace . "посмотри файлы проекта"
```

Заглушка не «думает», но вся цепочка (агент → роутер → провайдер → правка файла)
проверяется, и вы видите, что конфигурация собрана правильно.

## Если не работает

**«Не могу подключиться к http://127.0.0.1:8788/v1»**
Роутер не запущен или вы закрыли его окно. Запустите `windows\START-ROUTER.bat`.
Проверка: откройте <http://127.0.0.1:8788/health> — должно быть `{"status":"ok"}`.

**«Все бесплатные квоты на сегодня исчерпаны» (HTTP 429)**
Так и задумано: роутер честно сказал, что все ключи выработаны. Что делать:
1. смотрите панель <http://127.0.0.1:8788/> — видно, кто остывает и сколько минут;
2. добавьте второй ключ другого сервиса в `providers.json`;
3. поставьте локальную модель (`ollama pull qwen2.5-coder:7b`) — роутер сам её включит;
4. сброс дневных квот — в полночь по UTC (03:00 по Москве).

**Провайдер помечен «401/403 — плохой ключ»**
Ключ скопирован не полностью, истёк или аккаунт не активирован. Пересоздайте ключ.
Роутер сам переключится на других, работать можно уже сейчас.

**«Python не найден»**
Новое окно терминала: после установки через `winget` PATH обновляется только в новых окнах.

**Агент «не понимает» задачу / отвечает текстом вместо правок**
Слабая модель (например, локальная 7B). Смените маршрут: `/model smart` — или
разбейте задачу на более мелкие.

**Агент пишет «Достигнут предел шагов»**
Задача большая. Запустите с `--steps 60` или разделите на части.

**Windows пишет «выполнение сценариев отключено»**
Запускайте как в шаге 1, с `-ExecutionPolicy Bypass` (это разовый обход, систему не меняет).

**Хочу видеть всё, что происходит**
В `providers.json` стоит `"log_requests": true` — в окне роутера печатается каждый запрос:
провайдер, токены, ошибки.
