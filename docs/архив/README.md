# Архив: старые документы (схема «много бесплатных ключей»)

Всё в этой папке относилось к первой версии проекта — когда ключа не было вовсе и задача стояла
собрать бесплатный доступ из кусочков. Сейчас проект работает на купленном балансе SmartAPI,
и эти документы нужны только в двух случаях:

1. **баланс закончился**, а покупать пока не хочется — поднимаете бесплатный резерв;
2. **интересно посмотреть, как устроена схема ротации** из шести бесплатных провайдеров.

## Что здесь лежит

| Файл | О чём | Когда пригодится |
|---|---|---|
| `01-БЫСТРЫЙ-СТАРТ-бесплатные-ключи.md` | установка и запуск без единого платного ключа | если совсем нет доступа |
| `02-КЛЮЧИ-БЕСПЛАТНО.md` | как получить каждый бесплатный ключ (Gemini, Groq, Mistral, OpenRouter, NVIDIA, GLM) | поднять резерв |
| `03-ЛИМИТЫ-И-МОДЕЛИ.md` | таблица лимитов и арифметика ротации | понять, чего ждать от бесплатных |
| `04-БЕЗОПАСНОСТЬ-старая-версия.md` | предыдущая версия документа про безопасность | история |
| `05-ОДИН-ПЛАТНЫЙ-КЛЮЧ.md` | если надоела ротация: подписки вида OpenCode Go | альтернатива балансу |
| `06-ОПЛАТА-ИЗ-РОССИИ.md` | оплата рублями: polza.ai, AITUNNEL, ProxyAPI и другие агрегаторы | если SmartAPI перестанет устраивать |
| `07-ЧУЖИЕ-КЛЮЧИ-И-ШЛЮЗЫ.md` | почему «Claude за 30 ₽» — перепродажа чужого аккаунта | понять риски покупки баланса |
| `08-КАК-ПРОВЕРИТЬ-КЛЮЧ.md` | первая версия инструкции по проверке ключа | заменён на `docs/06` |
| `09-НЕ-ЗАПУСКАЙ-ЧУЖИЕ-УСТАНОВЩИКИ.md` | подробный разбор рисков чужого npm-установщика | заменён на `docs/05`, раздел 4 |
| `10-КУПИЛ-БАЛАНС-SMARTAPI.md` | первая версия инструкции по купленному балансу | заменён на `docs/02` и `docs/01` |

Готовые конфиги под эти схемы тоже остались в репозитории:
`router/providers.zen.json`, `router/providers.ru.json`, `router/providers.paid.json`,
`router/providers.example.json`.

**Не путайте:** рабочий конфиг сейчас — `router/providers.smartapi.json`.
Остальные существуют для случая «резерв понадобился».
