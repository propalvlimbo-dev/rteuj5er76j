# Проверка купленного ключа: инструкция

Если вы всё-таки купили «API-ключ на N токенов» — проверьте его **до** того, как пустите
туда работу. Инструмент `tools/check_api_key.py` прогоняет 13 проверок и говорит прямо,
соответствует ли ключ обещанному.

> 20 ₽ — разумная цена за то, чтобы узнать правду. Но **не отправляйте через такие ключи
> рабочий код, пароли, `.env` и персональные данные**: запросы идут через чужой шлюз,
> и владелец видит их содержимое целиком. Проверка — да, работа — нет.

---

## Запуск (одна команда)

```powershell
python tools\check_api_key.py ^
  --base-url https://адрес-из-инструкции-продавца/v1 ^
  --key ВАШ-КЛЮЧ ^
  --model claude-opus-5 ^
  --claimed-tokens 8000000 ^
  --price-rub 20 ^
  --report report.json
```

* `--base-url` — адрес шлюза из инструкции продавца (обычно оканчивается на `/v1`).
* `--model` — модель, которую обещали в лоте.
* `--claimed-tokens`, `--price-rub` — из описания лота; нужны для калькулятора экономики.
* `--report report.json` — сохранит отчёт, его можно приложить к требованию возврата.
* `--quick` — быстрый режим без тяжёлых тестов.

Код возврата `1` означает, что найдены критические проблемы — удобно для скриптов.

---

## Что проверяется и что считается проблемой

| Тест | Что значит красный флаг |
|---|---|
| **Подмена модели в ответе** | просили `claude-opus-5`, а в ответе `deepseek-v4-flash-free`. Шлюз молча отправил запрос на дешёвую модель |
| **Самоидентификация** | модель говорит о себе «я DeepSeek/Qwen/Llama», хотя продана как Claude/GPT |
| **Заявленная модель в каталоге** | модели из лота вообще нет в списке моделей шлюза |
| **Честность учёта токенов** | запрос на ~1200 токенов, а списано 6000 — те самые «коэффициенты». Баланс растает в 5 раз быстрее |
| **Поведение под нагрузкой** | 5 параллельных запросов → 429/таймауты. Это общий пул: агент делает сотни запросов за сессию и будет обрываться |
| **Tool calling и протокол `role=tool`** | шлюз не умеет инструменты → Cline, opencode и наш агент работать нормально не смогут |
| **Стриминг** | без потока ответы приходят целиком и заметно медленнее |
| **Утечки в текстах ошибок** | в ошибке видны адреса upstream (`opencode.ai/zen`) — это перепродажа чужого доступа |
| **Контекст ~30k знаков** | кодовое слово в середине текста не находится → шлюз режет контекст, агент «не видит» файлы целиком |
| **Экономика лота** | 8 млн токенов Opus по официальным ценам стоят ≈ $72, а продано за 20 ₽ — в 288 раз дешевле себестоимости. Так не бывает |

## Как выглядит отчёт (пример на «типичном» шлюзе)

```
  ✗ FAIL  Подмена модели в ответе
            просили 'claude-opus-5', а ответ помечен как 'deepseek-v4-flash-free'
  ! WARN  Самоидентификация модели
            говорит: Я DeepSeek V3, разработана DeepSeek; ⚠ модель называет себя другой семьёй
  ✗ FAIL  Честность учёта токенов
            запрос ~1227 токенов, а списано 6135 (×5.0). Похоже на «коэффициенты»
  ✗ FAIL  Поведение под нагрузкой
            2/5 успешно, 429: 3 — на 5 параллельных запросов приходит лимит
  ! WARN  Утечки в текстах ошибок
            в тексте ошибки видны следы upstream: opencode.ai → opencode/zen
  ✗ FAIL  Экономика лота
            8,000,000 токенов стоят ≈ 5760 ₽, а продано за 20 ₽ — в 288 раз дешевле

ИТОГО: провалено 4, предупреждений 3
```

Так выглядит лот, который гарантированно надо возвращать.

## Как требовать возврат

1. Сохраните отчёт (`--report report.json`) и сделайте скриншот вывода.
2. Напишите продавцу: «Ключ не соответствует описанию: подмена модели (заявлена Opus 5,
   отвечает DeepSeek), лимиты на 5 параллельных запросов, завышенный в 5 раз расход токенов.
   Прилагаю отчёт. Прошу возврат».
3. Если откажет — открывайте спор через арбитраж FunPay, приложив отчёт и скриншоты
   переписки. Такие отчёты принимают охотно: они объективны и воспроизводимы.
4. **Не продолжайте пользоваться ключом**: если он ворованный, доступ отключат в любой
   момент, а ваши данные уже ушли третьей стороне.

## Если решите этим пользоваться (не рекомендую, но честно)

Только как **дополнительный** канал, с низким приоритетом, и никогда — для кода с секретами.
Добавьте в `router/providers.json` ещё одного провайдера:

```json
{
  "name": "gateway",
  "kind": "openai",
  "base_url": "https://адрес-шлюза/v1",
  "keys": ["ваш-ключ"],
  "priority": 50,
  "models": ["claude-opus-5"],
  "limits": {},
  "notes": "Сторонний шлюз: используется только когда официальные источники недоступны"
}
```

Официальным источникам поставьте приоритет 1–10, локальной Ollama — 900. Тогда при любом
сбое чужака работа продолжится на нормальном канале, а вы даже не заметите.

## Не забывайте: то, что продают, обычно бесплатно

Модели из этого лота (`gpt-6-astra`, `claude-opus-5`, `claude-fable-5-1`) — каталог
**OpenCode Zen**. У Zen есть бесплатные модели: регистрация бесплатная, карта не нужна.
Настройка — одна команда:

```powershell
windows\START-ROUTER.bat router\providers.zen.json
```

Подробный разбор схемы — `docs/архив/07-ЧУЖИЕ-КЛЮЧИ-И-ШЛЮЗЫ.md`.
