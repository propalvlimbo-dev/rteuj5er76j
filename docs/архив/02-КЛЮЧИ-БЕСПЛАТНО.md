# Бесплатные ключи: где взять и что вставить

Все ключи вставляются в один файл — **`router/providers.json`** (в полях `"keys": [...]`).
Порядок не важен, можно начать с одного. Чем больше ключей — тем реже вы увидите слово «квота».

> Правило: **один аккаунт на сервис**. Не заводите десять аккаунтов Google, чтобы обойти
> лимит — это нарушает правила сервисов и приводит к блокировке. Правильный путь — разные
> сервисы, они дают независимые квоты.

---

## 1. Google AI Studio — начните с него (лучшее качество бесплатно)

1. Откройте <https://aistudio.google.com/apikey>
2. Войдите в Google-аккаунт (обычный, личный).
3. Кнопка **Create API key** → выберите/создайте проект → скопируйте ключ вида `AIza…`.

Вставьте в конфиг:

```json
{ "name": "google", "key_env": "GEMINI_API_KEY", "keys": ["AIza...ваш ключ..."] }
```

Что даёт: модели **Gemini 3.8 / 3.5 Flash, Flash-Lite** — бесплатно (Pro-модели платные).
Это лучший бесплатный вариант для сложных правок в коде.
Нюанс: на бесплатном тарифе Google может использовать запросы для улучшения продуктов —
не отправляйте туда чужие коммерческие тайны (для них есть локальная модель и Mistral).

---

## 2. Groq — самый быстрый (ответы за секунды)

1. Откройте <https://console.groq.com/keys>
2. Войдите через Google/GitHub.
3. **Create API Key** → скопируйте ключ `gsk_…`.

```json
{ "name": "groq", "key_env": "GROQ_API_KEY", "keys": ["gsk_..."] }
```

Что даёт: `openai/gpt-oss-120b`, `openai/gpt-oss-20b`, `qwen/qwen3.6-27b`.
Лимит на сен-2026: 30 запросов/мин, 1000 запросов/день, **но всего 200 000 токенов в день** —
это примерно 5–8 ходов агента с большим контекстом. Поэтому Groq — «ускоритель»,
а не основная лошадь.

---

## 3. Mistral — самый большой объём (≈1 млрд токенов/месяц)

1. Откройте <https://console.mistral.ai/api-keys>
2. Зарегистрируйтесь (нужна **верификация телефона** — это обязательное условие бесплатного тарифа «Experiment»).
3. **Create new key** → скопируйте.

```json
{ "name": "mistral", "key_env": "MISTRAL_API_KEY", "keys": ["..."] }
```

Что даёт: `codestral-latest` (модель именно для кода, держит длинные файлы),
`devstral-medium-latest`, `mistral-large-latest`, `mistral-small-latest`.
Лимит: ~1 запрос/сек, около 1 млрд токенов в месяц — при разумной работе хватает на месяцы.
Данные на бесплатном тарифе могут использоваться для улучшения моделей (можно отключить в настройках).

---

## 4. OpenRouter — много моделей одним ключом

1. Откройте <https://openrouter.ai/settings/keys>
2. Войдите через Google/GitHub (карта не нужна).
3. **Create Key** → скопируйте `sk-or-v1-…`.

```json
{ "name": "openrouter", "key_env": "OPENROUTER_API_KEY", "keys": ["sk-or-v1-..."] }
```

Что даёт: все модели с пометкой `:free` — gpt-oss-120b, Cohere North Mini Code,
Poolside Laguna, Nemotron, Gemma 4, GLM Air и другие. Список меняется каждую неделю:
актуальный — <https://openrouter.ai/models?max_price=0>; ID моделей можно дописать в
`"models"` у провайдера `openrouter`.

Лимит: 50 запросов/день бесплатно. **Один раз** пополнив баланс на $10, вы навсегда
получаете 1000 запросов/день к бесплатным моделям. Это единственные деньги, которые
имеют смысл во всей схеме.

---

## 5. NVIDIA NIM — 40 запросов/минуту без карты

1. Откройте <https://build.nvidia.com>
2. Выберите любую модель (например Qwen3-Coder) → кнопка **Get API Key** → войдите.
3. Скопируйте ключ `nvapi-…`.

```json
{ "name": "nvidia", "key_env": "NVIDIA_API_KEY", "keys": ["nvapi-..."] }
```

Что даёт: Qwen3-Coder 480B, DeepSeek, Kimi, Nemotron — 40 запросов/мин.
Тариф формально «для оценки», для личного использования подходит.
ID моделей копируйте со страницы модели: они периодически переименовываются.

---

## 6. Z.ai (GLM Flash) — быстрый резерв

1. Откройте <https://z.ai/manage-apikey/apikey-list>
2. Зарегистрируйтесь → **Create a new API key**.

```json
{ "name": "zai", "key_env": "ZAI_API_KEY", "keys": ["..."] }
```

Что даёт: бесплатные Flash-модели GLM (4.7 / 4.6 / 4.5).
Ограничение лицензии: не для коммерческого использования.

---

## 7. Без регистрации вообще — LLM7

В примере конфига уже прописан провайдер `llm7`: ключ не нужен, работает с заглушкой
`"unused"`. Модели слабые и медленные, но это аварийный канал, когда всё остальное
остыло, а интернет есть.

---

## 8. Локальная модель (главный пункт, если нужна настоящая бесконечность)

```powershell
winget install Ollama.Ollama     # или скачать с https://ollama.com/download
ollama pull qwen2.5-coder:7b     # ~5 ГБ, идёт на 16 ГБ RAM
```

Проверка:

```powershell
ollama run qwen2.5-coder:7b "привет"
```

Ничего вставлять в конфиг не нужно — провайдер `ollama` уже прописан с последним
приоритетом: роутер включает её автоматически, когда облачные квоты исчерпаны.
Она же работает без интернета вообще.

---

## Про переменные окружения (если не хотите хранить ключи в файле)

В конфиге вместо `keys` можно указать `key_env` — тогда ключ берётся из переменной
окружения. Список ключей разделяется запятой:

```powershell
setx GROQ_API_KEY "gsk_ключ1,gsk_ключ2"
```

Если ключей несколько (например, личный и рабочий аккаунт Groq), роутер сам переключится
на второй, когда первый упрётся в лимит.

---

## Проверка, что ключи работают

1. Запустите `windows\START-ROUTER.bat`.
2. Откройте <http://127.0.0.1:8788/> — в панели будет список провайдеров; у тех, где ключ
   не принят, появится «последняя ошибка: 401/403».
3. Быстрая проверка «в лоб»:

```powershell
curl http://127.0.0.1:8788/v1/chat/completions ^
  -H "Content-Type: application/json" ^
  -d "{\"model\":\"auto\",\"messages\":[{\"role\":\"user\",\"content\":\"скажи привет\"}]}"
```

Если в ответе есть `"choices"` — всё работает, и можно запускать агента.
