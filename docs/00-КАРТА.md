# Карта проекта: что где лежит

Всё, что нужно для работы, — три файла и три папки. Остальное служебное.

```
ИИ/
├── START.bat            запуск одним кликом: ключ → роутер → модель → папка → агент
├── START-ROUTER.bat     только роутер в своём окне (для VS Code: Cline, Continue, opencode)
├── install.ps1          установщик программ (нужен один раз, необязательный)
├── README.md            краткое описание проекта
│
├── app/                 программа
│   ├── launch.py          · то, что делает START.bat
│   ├── agent.py           · агент, с которым вы разговариваете
│   ├── router.py          · шлюз: дневной лимит и коэффициенты моделей
│   └── check_key.py       · проверка ключа и списка моделей шлюза
│
├── config/              настройки
│   ├── providers.json     · адреса SmartAPI, модели, коэффициенты, лимит tpd
│   ├── opencode.json      · конфиг opencode
│   └── continue.yaml      · конфиг Continue для VS Code
│
├── docs/                инструкции (см. список ниже)
└── dev/                 служебное: автотесты и разбор npm-пакетов (трогать не нужно)
```

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| «Python не найден» | поставить Python с python.org, галочка *Add Python to PATH*, новое окно |
| Ключ не принимается | новый ключ в кабинете SmartAPI, запустить `START.bat` заново |
| Модель «не существует» | `/model` в агенте — там актуальный список моделей шлюза |
| Агент отвечает, но ничего не меняет | проверьте папку проекта (шаг 4 запуска) и что задача названа конкретно |
| Тратится много токенов | `/tokens` покажет, что занимает место; `/clear` между задачами |
| Нужно откатить правки | `/diff` — что изменилось, `/undo` — вернуть как было |
| Агент забыл, о чём была речь | `/history` — что помнит; продолжения он понимает сам |

## Три вещи, которые стоит помнить

1. **Одно окно.** Роутер и агент живут вместе; отдельное окно нужно только для редакторов
   (`START-ROUTER.bat`).
2. **Расход виден в каждой строке шага:** `вход 2.0K / выход 220 · сегодня 4.5K/400K`.
3. **Каждая задача — это история, которую модель читает заново на каждом шаге.** Чем короче
   сессия и чем конкретнее задача, тем дешевле результат.
