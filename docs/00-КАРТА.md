## Что лежит в репозитории

```
ELYTRIX.bat              запуск консоли двойным кликом (Windows)
ELYTRIX-ROUTER.bat       запуск шлюза для редакторов двойным кликом (Windows)
README.md                общий обзор: запуск, команды, модели, экономия
app/run.py               точка входа для bat-файлов (добавляет app/ в пути)
app/elytrix/             сам агент — 13 модулей, только стандартная библиотека
config/elytrix.json      настройки: шлюз, модели и коэффициенты, лимиты, темы
dev/tests/               326 тестов (unittest) и подставной шлюз mockapi.py
docs/                    эти документы
```

Профиль пользователя (ключ, расход, последняя папка, тема) хранится отдельно —
в `~/.elytrix/`, а не в репозитории. Резервные копии правок агент складывает в
`<папка проекта>/.elytrix/backups/<сессия>/`.

## Три режима работы

| Режим | Как включить | Когда нужен |
|---|---|---|
| **Консоль** (полноэкранный интерфейс) | `ELYTRIX.bat` · `python app/run.py` | основная работа: задачи словами, правки, откат |
| **Одна задача** | `python app/run.py "почини тесты"` | скрипты, CI, быстрый вопрос без интерфейса |
| **Роутер** | `/router` в консоли · `ELYTRIX-ROUTER.bat` · `--router` | только если работаете в редакторе, которому нужен HTTP-адрес |

Консоли роутер **не нужен**: агент ходит в SmartAPI напрямую, а учёт токенов, дневной
лимит, коэффициенты моделей и переключение между форматами шлюза живут внутри него.

## Если что-то не так

Первое действие — диагностика:

```
python app/run.py --doctor
```

Она проверяет ключ, доступность шлюза, список моделей, рабочую папку, лимиты и права
файла ключа. Дальше — раздел «Частые проблемы» в [01-БЫСТРЫЙ-СТАРТ.md](01-БЫСТРЫЙ-СТАРТ.md).
