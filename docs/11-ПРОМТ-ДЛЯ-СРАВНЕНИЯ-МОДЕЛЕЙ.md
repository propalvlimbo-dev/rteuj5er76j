# Промт для сравнения моделей (одностраничный сайт)

Задача одна и та же для всех моделей — так честнее сравнивать. Копируйте текст ниже
целиком и вставляйте агенту (в окне FreeCoder правый клик мыши = вставка из буфера).

---

## Промт (копировать целиком)

```
Сделай одностраничный сайт кофейни «Тёплый угол» в текущей папке.

Требования:

1. Один файл index.html — HTML, CSS и JavaScript внутри него. Никаких внешних
   библиотек, шрифтов, картинок и CDN: файл должен работать офлайн, если открыть
   его двойным щелчком.

2. Блоки сверху вниз:
   - шапка: название и три ссылки-якоря (Меню, О нас, Контакты);
   - главный экран: крупный заголовок, подзаголовок в одну строку, кнопка «Смотреть меню»;
   - меню: три карточки кофе — название, цена, короткое описание — сеткой;
   - блок «О нас»: заголовок и 3-4 предложения текста;
   - форма «Заказать звонок»: имя, телефон, кнопка «Жду звонка»;
   - подвал: адрес, часы работы, год.

3. Адаптивность: на ширине 360 px — одна колонка, ничего не выезжает за экран;
   на 1440 px — карточки в ряд, ширина контента ограничена.

4. Оформление: тёплая тёмная тема, системные шрифты, аккуратные отступы,
   закруглённые карточки, плавные переходы при наведении на кнопки и карточки,
   плавная прокрутка по якорям.

5. Форма без alert: телефон проверяется (только цифры, пробелы, +, -, скобки,
   не меньше 10 цифр). При ошибке под полем красный текст с причиной, при успехе —
   зелёный текст «Перезвоним в течение 15 минут», поля очищаются.

6. Семантические теги (header, main, section, footer), у кнопок и полей —
   подписи для экранных читалок.

7. Не использовать alert, console.log и внешние зависимости. Готовый файл
   положи в index.html и скажи одной строкой, что сделал.
```

Ровно этот текст без правок — всем моделям. Если поменять формулировку, сравнение
перестанет быть честным.

---

## Как проводить сравнение

1. Создайте папки по одной на модель, например внутри `C:\Users\admin\Desktop\ИИ\сравнение`:
   `luna`, `sonnet`, `opus-4-8`, `opus-5`. В одной папке подряд не надо — файлы смешаются.
2. `START.bat` → рабочая папка → модель → вставить промт. После задачи смотрите
   строку итога (`шагов N из 15 · токенов вход/выход`) и `/tokens`.
3. Откройте `index.html` двойным щелчком, проверьте адаптив: F12 → Ctrl+Shift+M → 360 px.

| Пункт меню | Модель | Множитель | Зачем в сравнении |

Можно добавить пятую — любую из полного списка (пункты 5+): gpt-5.6-sol, gpt-5.6-terra,
claude-opus-4-7, gpt-6-astra.

Ориентир по расходу: одна такая задача — примерно 10–25 тыс. зачётных токенов на модель,
то есть четыре модели — это 40–100 тыс. из 400 000 в день.
