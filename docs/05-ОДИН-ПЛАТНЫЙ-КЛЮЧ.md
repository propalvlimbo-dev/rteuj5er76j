# Вместо ротации ключей: один платный ключ за $10/мес

Если надоело жонглировать бесплатными ключами — вот короткий путь. Один ключ, один раз настроить,
дальше просто работаете. Бесплатные остаются в резерве, но вы их не увидите.

---

## Вариант №1 — OpenCode Go, $10/мес (рекомендую)

**Почему именно он:** самый дешёвый способ получить много сильных моделей одним ключом,
и `opencode` у вас уже установлен нашим установщиком.

1. Откройте <https://opencode.ai/auth> → зарегистрируйтесь (первый месяц $5).
2. Возьмите API-ключ.
3. Дальше два пути на выбор:

**Путь А (проще, без роутера вообще):**
```
opencode
/connect      → выберите OpenCode Go → вставьте ключ
/models       → выберите модель (glm-5.2, deepseek-v4-pro, kimi-k2.7-code)
```
Всё. Дальше просто пишете задачу — opencode сам правит файлы в папке, показывает diff.

**Путь Б (через наш роутер — если хотите запас бесплатных моделей):**
```powershell
# положите ключ в переменную окружения
setx OPENCODE_API_KEY "ваш-ключ"
```
Откройте `router\providers.paid.json` — там всё уже готово — и запустите:
```powershell
python router\freecoder_router.py --config router\providers.paid.json
```
Дальше как обычно: `windows\START-AGENT.bat` или Cline/Kilo в VS Code.

**Что внутри за $10:** GLM-5.2, DeepSeek V4 Pro / Flash, Kimi K2.7 Code, MiniMax M3, Qwen3.7 Plus,
MiMo и ещё ~15 моделей. Лимиты: например DeepSeek V4 Flash — ~31 000 запросов за 5 часов,
GLM-5.2 — ~880 за 5 часов. Обычная работа агента такие объёмы не выбирает.

## Вариант №2 — pay-per-use вместо подписки ($2–5/мес по факту)

Не хотите подписку — платите за токены, это буквально копейки:

| Сервис | Цена | Как |
|---|---|---|
| **OpenCode Zen** | оплата по факту, без подписки | тот же ключ с opencode.ai/auth, в `providers.paid.json` включите `opencode-zen` (`enabled: true`) |
| **DeepSeek API** | центы за миллион токенов | console.deepseek.com → пополнить $2–5 → ключ в `providers.paid.json` у `deepseek` |
| **Z.ai pay-as-you-go** | ~$1.4 вход / $4.4 выход за 1M | для GLM-5.1 |

Обычная работа агента — это 1–3 млн токенов в месяц, то есть **$1–5**. Никаких подписок и лимитов.

## «А может просто сайт?»

Сайты-агенты (Codex cloud, Jules, Copilot coding agent) умеют править код, **но только в вашем
репозитории на GitHub**, а не в локальной папке. Схема такая: залить проект на GitHub → дать агенту
задачу в браузере → забрать изменения через `git pull`. Это лишний слой, работает медленнее и требует
интернета всегда.

Для «отредактируй мою папку на компьютере нормально» локальные инструменты лучше и ничем не хуже
по качеству — тот же opencode (200k★ на GitHub), Cline или Claude Code, работающие на той же модели,
что и облачные сервисы.

## Как переключиться с бесплатного режима на платный за 1 минуту

1. Получите ключ (OpenCode Go / DeepSeek / GLM — см. выше).
2. `router\providers.paid.json` → впишите ключ в поле `keys` у нужного провайдера.
3. Запускайте роутер с этим файлом:
   ```powershell
   python router\freecoder_router.py --config router\providers.paid.json
   ```
   (или допишите `--config router\providers.paid.json` в `windows\START-ROUTER.bat`)
4. Всё остальное не меняется: агент, opencode, VS Code, панель на <http://127.0.0.1:8788/>.

Теперь основной ответ даёт платная модель, а бесплатные подхватят только если она недоступна.
