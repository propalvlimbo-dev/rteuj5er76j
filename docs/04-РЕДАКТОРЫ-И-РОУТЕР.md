# Редакторы и роутер

ELYTRIX работает со SmartAPI напрямую, и для самой консоли роутер не нужен. Но Cline,
Continue, Kilo Code, opencode и Cursor умеют говорить только с HTTP-адресом — для них
агент может поднять совместимый шлюз на вашем компьютере.

```
   редактор (Cline / Continue / opencode / Cursor)
        │  http://127.0.0.1:8789/v1     ключ — любой, например «elytrix»
        ▼
   ELYTRIX router   ← коэффициенты моделей, дневной лимит, промпт-кэш,
        │              failover между форматами шлюза, учёт расхода
        ▼
   https://api.smartapi.shop
```

Настоящий ключ SmartAPI редактору не передаётся: роутер держит его у себя. Расход
редактора попадает в тот же учёт, что и расход консоли, — дневной лимит общий.

## Запуск

**Внутри консоли** (удобно, когда работаете и там, и там):

```
/router              поднять на порту из конфига (8789)
/router 9000         поднять на своём порту
/router stop         остановить
```

**Отдельным окном** (Windows) — двойной клик:

```
ELYTRIX-ROUTER.bat        (порт по умолчанию 8789)
ELYTRIX-ROUTER.bat 9000   (свой порт)
```

**Из терминала:**

```
python app/run.py --router            # порт из config/elytrix.json → router.port
python app/run.py --router 9000
python app/run.py --router --host 127.0.0.1
```

Окно роутера печатает адрес и после каждого запроса — модель, коэффициент, токены
и расход за сутки. Не закрывайте его, пока работаете в редакторе. Остановка — **Ctrl+C**
(состояние расхода сохраняется).

Если ключ не задан, роутер не запустится и скажет, что делать: запустите сначала
`ELYTRIX.bat` — он спросит ключ и сохранит в профиль.

## Адрес для редактора

| Поле | Значение |
|---|---|
| Base URL | `http://127.0.0.1:8789/v1` |
| API key | любой непустой, например `elytrix` |
| Model | `auto` · `cheap` · `smart` · `max` или конкретная модель (`gpt-5.6-luna`, `claude-opus-5`) |

Маршруты удобны тем, что модель можно поменять в одном месте (`config/elytrix.json` →
`models.aliases`), не трогая настройки редактора.

## Примеры настроек

### Cline (VS Code)

API Provider: **OpenAI Compatible**

```
Base URL:  http://127.0.0.1:8789/v1
API Key:   elytrix
Model ID:  auto
```

### Continue

`~/.continue/config.yaml`:

```yaml
models:
  - name: ELYTRIX (auto)
    provider: openai
    model: auto
    apiBase: http://127.0.0.1:8789/v1
    apiKey: elytrix
```

### opencode

`opencode.json` в проекте:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "elytrix": {
      "npm": "@ai-sdk/openai-compatible",
      "options": { "baseURL": "http://127.0.0.1:8789/v1", "apiKey": "elytrix" },
      "models": { "auto": {}, "smart": {}, "max": {} }
    }
  },
  "model": "elytrix/auto"
}
```

### Cursor

Settings → Models → **OpenAI API Key**: `elytrix`, затем **Override OpenAI Base URL**:
`http://127.0.0.1:8789/v1`, и добавьте модель вручную: `auto` (или `gpt-5.6-luna`).

### Kilo Code / Roo Code

Как в Cline: провайдер **OpenAI Compatible**, тот же Base URL, ключ любой,
модель `auto`.

## Маршруты роутера

| Метод и путь | Что делает |
|---|---|
| `POST /v1/chat/completions` | формат OpenAI; `stream: true` поддержан (SSE, заканчивается `data: [DONE]`) |
| `POST /v1/messages` | формат Anthropic; `stream: true` поддержан (`message_start` … `message_stop`) |
| `GET /v1/models` | список маршрутов и моделей с коэффициентами (`multiplier`, `alias`, `description`) |
| `GET /status.json` | расход за сутки, лимит, кэш, последние клиенты, адреса шлюза |
| `GET /health`, `/healthz` | жив ли сервер, версия, модель по умолчанию |
| `GET /` | то же человекочитаемым текстом |
| `OPTIONS` | предзапрос CORS: разрешены `GET, POST, OPTIONS`, любые заголовки |

Неизвестный путь — `404` с JSON-ошибкой, невалидный JSON — `400`. Ошибка шлюза
приходит как `502` (OpenAI: `{"error": {...}}`, Anthropic: `{"type": "error", ...}`),
а `429` — как `429`, чтобы редактор сам притормозил. В потоковом режиме ошибка
отправляется событием внутри потока, а затем `data: [DONE]` — редактор не зависает.

### Инструменты агента

Если редактор прислал свои `tools` — они и используются. Если `tools` нет, но по
системному промпту видно, что это агент (упоминаются инструменты и файлы), роутер
подставляет свой набор: `ls`, `read`, `grep`, `write`, `edit`, `bash`. Обычному чату
инструменты не добавляются — это лишние токены.

### Параллельные запросы

Редакторы умеют слать несколько запросов сразу. У роутера пул до четырёх клиентов
SmartAPI: каждый со своим keep-alive соединением, поэтому стриминг одного запроса не
ломает другой. Число клиентов видно в `/status.json` → `clients`.

## Проверка руками

```bash
curl http://127.0.0.1:8789/health
curl http://127.0.0.1:8789/v1/models
curl http://127.0.0.1:8789/status.json

curl http://127.0.0.1:8789/v1/chat/completions \
  -H "Content-Type: application/json" -H "Authorization: Bearer elytrix" \
  -d '{"model":"auto","messages":[{"role":"user","content":"скажи ок"}]}'

curl http://127.0.0.1:8789/v1/messages \
  -H "Content-Type: application/json" -H "x-api-key: elytrix" \
  -d '{"model":"auto","max_tokens":64,"messages":[{"role":"user","content":"скажи ок"}]}'
```

## Учёт и лимиты

Роутер использует тот же профиль `~/.elytrix/`: расход за сутки, дневной лимит,
статистику по моделям и состояние кэша. Изменение лимита в консоли (`/limit 600000`)
действует и на роутер — клиенты пула подхватывают новое значение на следующем запросе.

Проверить расход, не вставая из редактора:

```bash
curl http://127.0.0.1:8789/status.json
```

```json
{
  "app": "ELYTRIX", "version": "3.1.1", "uptime_s": 1284,
  "model": "claude-sonnet-4-6", "default_alias": "auto",
  "day_tokens": 17680, "day_limit": 400000, "day_requests": 4,
  "by_model": {"claude-sonnet-4-6": {"tokens": 17680, "requests": 4, "cache_read": 3120}},
  "cache": {"enabled": true, "supported": true, "read_tokens": 3120},
  "session": {"tokens_in": 8200, "tokens_out": 640, "charged": 17680},
  "clients": 2,
  "gateway": {"anthropic": "https://api.smartapi.shop",
              "openai": "https://api.smartapi.shop/v1"}
}
```

## Безопасность

- Роутер слушает только `127.0.0.1`: с других машин он недоступен. Не меняйте `--host`
  на `0.0.0.0` — вместе с адресом вы откроете и свой баланс.
- Ключ редактору не нужен: подойдёт любое непустое значение. Настоящий ключ хранится в
  `~/.elytrix/credentials.json` с правами `600`.
- Файловые инструменты роутера работают в той же папке, что и консоль (`-w` /
  `last_workspace`), и так же заперты в её пределах; секретные файлы (`.env`, `*.key`,
  `id_rsa`) не читаются.
- Разрушительные команды в `bash` отклоняются до выполнения.

## Если что-то не так

| Симптом | Причина и действие |
|---|---|
| Редактор пишет «connection refused» | роутер не запущен: `/router` в консоли или `ELYTRIX-ROUTER.bat` |
| «порт занят» | поднимите на другом: `/router 9000`, в редакторе поменяйте порт |
| `401` от редактора | роутер не проверяет ключ редактора; `401` приходит от шлюза — значит ключ SmartAPI неверный: `/key` |
| `429` | шлюз просит притормозить: роутер ждёт и повторяет, при частых `429` возьмите модель дешевле |
| «дневной лимит исчерпан» | снимите (`/limit 0`) или поднимите (`/limit 800000`) |
| Ответы обрываются | посмотрите окно роутера: там печатается модель, токены и ошибка |
| Редактор не видит инструменты | пришлите `tools` в запросе явно либо убедитесь, что системный промпт редактора упоминает инструменты и файлы |
