# Подключение приложений к SmartAPI

Два пути. **Через роутер** — рекомендуется: дневной лимит, учёт коэффициентов, выбор модели
одной командой. **Напрямую** — если приложение вы не хотите менять, а нужен только шлюз.

| Приложение | Путь | Что вписывать |
|---|---|---|
| Свой агент, opencode, Cline, Kilo Code, Continue | через роутер | `http://127.0.0.1:8788/v1` |
| Claude Code | напрямую (или через роутер) | `https://api.smartapi.shop` |
| Cursor, Codex, ChatGPT-подобные клиенты | напрямую | `https://api.smartapi.shop/v1` |

---

## Путь 1: через роутер (рекомендуется)

```powershell
windows\START-SMARTAPI.bat
```

Ключ вписывается один раз в переменную окружения, приложениям он не нужен — их ключ к роутеру
любой (`freecoder`). Дальше во всех клиентах:

| Поле | Значение |
|---|---|
| Base URL / API Base | `http://127.0.0.1:8788/v1` |
| API Key | `freecoder` (роутер не проверяет, главное — не пусто) |
| Model | `auto` (Sonnet 4.6) · `smart` (Opus 4.8) · `max` (Opus 5) · `cheap` (GPT-5.6 Luna) · `code` · `fable` |

Плюсы: расход виден в окне роутера после каждого запроса, дневной лимит работает, и при отказе
одного адреса шлюза запрос уходит на второй — приложение этого не заметит.

Минус: роутер должен быть запущен (одно окно на компьютере).

Готовые конфиги уже лежат в репозитории:

* `opencode/opencode.json` — для opencode (куда положить — в комментарии внутри файла);
* `vscode/continue-config.yaml` — для Continue в VS Code;
* для Cline / Kilo Code конфига нет, всё вводится в интерфейсе: провайдер
  **OpenAI Compatible** → данные из таблицы выше.

## Путь 2: напрямую в SmartAPI

### Claude Code

Файл `%USERPROFILE%\.claude\settings.json` (Windows) или `~/.claude/settings.json`:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.smartapi.shop",
    "ANTHROPIC_AUTH_TOKEN": "sk-smart-ВАШ-КЛЮЧ",
    "ANTHROPIC_MODEL": "sonnet-4.6"
  }
}
```

Затем перезапустить `claude`. Модель `opus-4.8` — когда действительно нужна максимальная
мощность (×4 по расходу). Для контекста в миллион токенов есть вариант `opus-4.8[1m]`.

> В инструкции продавца основной моделью указан `opus-4.8`. Это ×4 — самый быстрый способ
> сжечь 8 млн. Ставьте `sonnet-4.6` (×2) и переключайтесь на Opus вручную.

### opencode напрямую

`%USERPROFILE%\.config\opencode\opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "smartapi": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "SmartAPI",
      "options": {
        "baseURL": "https://api.smartapi.shop/v1",
        "apiKey": "{env:SMARTAPI_KEY}"
      },
      "models": {
        "sonnet-4.6": { "name": "Sonnet 4.6 (×2)" },
        "opus-4.8": { "name": "Opus 4.8 (×4)" }
      }
    }
  },
  "model": "smartapi/sonnet-4.6"
}
```

Если версия opencode не понимает `{env:SMARTAPI_KEY}`, впишите ключ строкой — но файл тогда
не выкладывайте и не коммитьте.

### Cline / Kilo Code (VS Code)

Настройки расширения → провайдер **OpenAI Compatible**:

| Поле | Значение |
|---|---|
| Base URL | `https://api.smartapi.shop/v1` |
| API Key | `sk-smart-…` |
| Model ID | `sonnet-4.6` |

### Continue (VS Code)

`%USERPROFILE%\.continue\config.yaml`:

```yaml
name: SmartAPI
version: 1.0.0
schema: v1
models:
  - name: Sonnet 4.6
    provider: openai
    model: sonnet-4.6
    apiBase: https://api.smartapi.shop/v1
    apiKey: sk-smart-ВАШ-КЛЮЧ
    roles: [chat, edit, apply]
```

### Cursor, Codex и прочие OpenAI-клиенты

Везде одно и то же:

| Поле | Значение |
|---|---|
| Base URL | `https://api.smartapi.shop/v1` |
| API Key | `sk-smart-…` |
| Model | `sonnet-4.6` |

* **Cursor:** Settings → Models → переопределить OpenAI Base URL и добавить имя модели вручную.
* **Codex CLI:** `%USERPROFILE%\.codex\config.toml` — секция `model_providers` с `base_url`
  и `env_key = "SMARTAPI_KEY"`.
* **Свои скрипты:** ключ из переменной окружения, а не из кода:

  ```powershell
  setx SMARTAPI_KEY "sk-smart-ВАШ-КЛЮЧ"    # один раз, затем новое окно терминала
  ```

## Как убедиться, что подключение живое

Проверяльщик из репозитория умеет оба формата:

```powershell
# формат Anthropic (Claude Code, Anthropic SDK)
python tools\check_api_key.py --base-url https://api.smartapi.shop ^
  --key %SMARTAPI_KEY% --model sonnet-4.6 --format anthropic --report smartapi-report.json

# формат OpenAI (Cline, Continue, Cursor, свои скрипты)
python tools\check_api_key.py --base-url https://api.smartapi.shop/v1 ^
  --key %SMARTAPI_KEY% --model sonnet-4.6 --format openai --report smartapi-report.json
```

Если через роутер что-то не отвечает, сначала проверьте сам роутер:

```powershell
curl http://127.0.0.1:8788/health      # {"status":"ok", ...}
curl http://127.0.0.1:8788/v1/models   # список алиасов: auto, smart, cheap, free, local
```

## Частые вопросы

**Нужно ли прописывать ключ в каждом приложении?**

Нет. Через роутер ключ нужен только роутеру. Напрямую — да, каждому.

**Что будет, если ключ отзовут?**

Через роутер работать не получится: он вернёт понятную ошибку про ключ, а не «непонятный сбой».
Напрямую — приложение начнёт отдавать `401`. В обоих случаях создайте новый ключ и замените его.

**Можно ли держать и роутер, и прямое подключение?**

Да, но тогда расход в редакторе не попадёт в общий учёт — прямые запросы идут мимо роутера.
Если важна экономия, лучше держать всё через роутер.
