# Консоль ELYTRIX

Полный справочник интерфейса: как устроен экран, что нажимать, какие есть команды,
темы и диалоги.

## Экран

```
 ELYTRIX 3.2.3                    claude-sonnet-4-6 ×2 │ my-project │ ask   ← шапка
──────────────────────────────────────────────────────────────────────────────
  → в api.py падает get_user — найди и починь                                ← лента
  ✓ grep      get_user · 4 совпадения · 0.1с
  ✓ read      api.py · строки 120—180 · 0.0с
  ⏵ edit      api.py …
  Ответ модели печатается здесь по мере генерации…
  ● готово за 12.4с · 3 шага · вх 8.2K · вых 640 · списано 17 680 зачётных    ← активность
 /model — выбрать модель, /tokens — куда уходят токены                        ← совет
 ╭──────────────────────────────────────────────────────────────────────────╮
 │ > здесь вы пишете задачу                                                 │  ← ввод
 ╰── Enter — отправить · Alt+Enter — строка · /help ────────────────────────…
 ctx 4% │ вх 8.2K │ вых 640 │ кэш 3.1K │ 4 запроса за день │ ×2 │ день 17K/400K █░░░░░░░░░
```

**Шапка** — версия, текущая модель с коэффициентом расхода, рабочая папка и режим
правок (`ask` / `auto` / `readonly`).

**Лента** — всё, что произошло: ваши задачи (`→`), шаги инструментов (`✓` готов,
`✗` ошибка, `⏵` выполняется), ответы модели, служебные сообщения (`•`) и ошибки.
Лента прокручивается, а не убегает вверх: экран не перерисовывается целиком, пока вы
не листаете.

**Старт** — в пустой ленте встречает логотип ELYTRIX (розово-белый градиент, в узком
окне — одна строка) и две строки сути: папка · модель · режим правок и подсказка
«напишите задачу и Enter · /help · Ctrl+Shift+C/V». Лишнего текста на старте нет:
подробности — в `/help`.

**Активность** — что агент делает сейчас (спиннер, шаг, инструмент) или итог последней
задачи: время, число шагов, токены и списанные зачётные.

**Совет** — одна из восьми подсказок, меняется каждые 12 секунд.

**Ввод** — многострочное поле в рамке: до 6 видимых строк, длинная строка переносится,
история задач по ↑↓. Рамка подсвечивается, когда агент занят.

**Статус** — доля использованного контекста модели, токены на вход и выход за сессию,
прочитанное из кэша, число запросов за день, коэффициент текущей модели и расход из
дневного лимита со шкалой.

## Большие промты

- **Alt+Enter** — перенос строки внутри задачи; в поле видно 6 строк, остальное листается.
- **Ctrl+Shift+V** или `/paste` — вставка из буфера: многострочный текст приходит целиком
  и не отправляется, пока не нажмёте Enter.
- **`/prompt spec.md`** — загрузить промт из файла проекта прямо в строку ввода:
  удобно, когда текст задания длиннее окна. Правите и отправляете Enter.
- **`python -m elytrix prompt.txt`** — выполнить задачу из файла вовсе без консоли.
- Или сошлитесь на файл в самой задаче: «сделай по @spec.md» — агент прочитает его сам.

## Клавиши

### Ввод задачи

| Клавиша | Действие |
|---|---|
| **Enter** | отправить задачу (или команду `/…`) |
| **Alt+Enter**, **Ctrl+J** | перенос строки — многострочная задача |
| **↑ / ↓** | история задач; в многострочном тексте — ход по строкам |
| **← / →**, **Home / End**, **Ctrl+A / Ctrl+E** | ход по строке |
| **Backspace / Delete** | удалить символ |
| **Ctrl+W** | стереть слово перед курсором (путь режется по сегментам `/`) |
| **Ctrl+U** | стереть всё до курсора |
| **Ctrl+K** | стереть всё после курсора |
| **Ctrl+Shift+V**, `/paste` | вставить буфер обмена в строку (работает и в поле диалога) |
| **Ctrl+Shift+C**, `/copy` | скопировать строку ввода, а если она пуста — последний ответ модели |
| **Ctrl+V** (вставка из буфера) | многострочный текст вставляется целиком и **не** отправляется |
| **Esc** | очистить поле ввода |
| **Ctrl+D** | очистить ввод; на пустом вводе — выход |

### Во время работы агента

| Клавиша | Действие |
|---|---|
| **любые символы, Backspace, Ctrl+W/U/K** | печатаются в строку заранее (typeahead, как в opencode): ввод не теряется, пока агент работает; Enter отправит текст, когда агент освободится |
| **Esc**, **Ctrl+C** | остановить задачу: обрывается текущий запрос, сделанные правки остаются |
| **Ctrl+C** ещё раз | сообщить, что остановка идёт (ждём ответа шлюза) |
| **PageUp / PageDown**, **Ctrl+↑ / Ctrl+↓** | листать ленту, пока агент работает |
| **Ctrl+V** | подробный вывод результатов инструментов |

### В покое

| Клавиша | Действие |
|---|---|
| **Ctrl+C** дважды за 1.5 с | выход |
| **Ctrl+D** | выход |
| **Ctrl+L** | перерисовать экран |
| **Ctrl+R** | куда уходят токены (`/tokens`) |
| **Ctrl+V** | подробный вывод |
| **PageUp / PageDown** | листать ленту |
| **Tab** | дописать команду или путь |

### В диалоге

| Клавиша | Действие |
|---|---|
| **↑ ↓**, **PageUp/PageDown**, **Home/End** | ход по списку или тексту |
| **Enter** | выбрать / подтвердить |
| **Esc**, **Ctrl+C** | закрыть без изменений |
| цифры **1…9** | прыжок к пункту списка |
| буквы | фильтр списка (в диалогах, где он разрешён) |

## Подсказки при вводе

- **Команды.** Начните с `/` — появится список всех команд; продолжайте печатать
  (`/mod`) — список сузится. **Tab** или **Enter** подставляет выбранный вариант.
- **Пути к файлам.** Напишите `@` и начало пути (`@src/ap`) — агент предложит файлы
  и папки рабочей папки. **Tab** подставляет путь целиком.
- **Модели.** В диалоге `/model` можно печатать название: `luna` находит маршрут
  `cheap → gpt-5.6-luna`, `gpt-5.6-luna` — саму модель. Цифры при этом листают список,
  пока вы не начали набирать текст.

## Команды

### Модель и расход

| Команда | Что делает |
|---|---|
| `/model` | диалог выбора: маршруты `auto/cheap/smart/max`, затем все модели с коэффициентом и оценкой цены. Смена модели очищает историю — за старый контекст не платим |
| `/model max` | то же без диалога |
| `/model gpt-6-astra` | модель, которой нет в каталоге: расход считается как ×1 |
| `/tokens`, `/cost`, `/ctx` | диалог: сколько занято контекста, что прочитано из кэша, расход за сутки по моделям, последние запросы |
| `/limit 600000` | дневной лимит зачётных токенов; `/limit 0` — снять; без числа — показать текущий |
| `/steps 12` | потолок шагов на задачу; без числа — показать текущий |
| `/models reload` | запросить у шлюза список моделей и добавить новые в каталог |

### История и контекст

| Команда | Что делает |
|---|---|
| `/clear`, `/new` | новая тема: забыть историю, память сессии и очистить ленту |
| `/compact` | сжать историю вручную (три ступени, без платного запроса к модели) |
| `/session`, `/history` | что агент помнит о прошлых задачах этого окна |

### Файлы

| Команда | Что делает |
|---|---|
| `/diff` | изменения файлов за сессию (унифицированный дифф, цветной) |
| `/undo`, `/revert` | откатить все правки сессии: изменённые файлы возвращаются к исходному виду, созданные агентом — удаляются |
| `/tree`, `/ls` | дерево файлов проекта (без `node_modules`, `.git`, сборок) |
| `/cd` | сменить рабочую папку: список недавних, текущая, «ввести путь…» |
| `/cd D:\code\project` | то же без диалога |

### Режим и вид

| Команда | Что делает |
|---|---|
| `/confirm` | режим правок: `ask` (спрашивать, показывать дифф), `auto` (править сразу), `readonly` (только чтение) |
| `/confirm auto` | то же без диалога |
| `/copy` | копировать строку ввода или последний ответ в буфер обмена |
| `/paste` | вставить буфер обмена в строку ввода |
| `/verbose` | показывать содержимое результатов инструментов и диффы в ленте |
| `/verbose on` / `off` | то же без диалога |
| `/theme` | тема оформления: `rose`, `dark`, `night`, `light`, `mono` |
| `/theme night` | то же без диалога |

### Служебные

| Команда | Что делает |
|---|---|
| `/help`, `/h`, `/?` | справка: все команды, клавиши и советы по экономии |
| `/api` | загрузить ключ: диалог, `/api sk-smart-…` или `/api ключ.txt` (проверяется контрольным запросом) |
| `/key` | синоним `/api` |
| `/doctor` | диагностика: ключ, шлюз, модели, кэш, лимиты, папки |
| `/router` | поднять шлюз для редакторов на порту из конфига; `/router 9000` — на своём порту; `/router stop` — остановить |
| `/exit`, `/quit`, `/q` | выход |

Неизвестная команда не ошибка: агент напишет `нет команды /…` и предложит похожие.

## Диалоги

**Подтверждение правки** (режим `ask`) — показывает инструмент, файл, дифф или команду:

```
╭─ edit ────────────────────────────────────────────────╮
│  правка api.py                                        │
│  --- a/api.py                                         │
│  +++ b/api.py                                         │
│  @@ -142,1 +142,3 @@                                  │
│  -    return user["id"]                                │
│  +    if not user:                                     │
│  +        return None                                  │
│  y — применить · a — всегда · n — пропустить · s — стоп │
╰───────────────────────────────────────────────────────╯
```

**y / д** — применить, **a / в** — применять дальше без вопросов (до конца задачи),
**n / и** — пропустить эту правку (агент получит отказ и попробует иначе),
**s** — остановить задачу. **Esc** считается отказом.

**Список** (`/model`, `/theme`, `/confirm`, `/cd`) — выбор стрелками, цифрами или
набором текста.

**Текст** (`/help`, `/tokens`, `/diff`, `/tree`, `/session`, `/doctor`) — прокрутка
PageUp/PageDown, стрелками, Ctrl+U/Ctrl+D; закрытие — Esc.

**Ввод строки** (`/api`, путь к папке) — обычное редактирование; для ключа символы
заменяются точками. Enter с пустым значением показывает ошибку проверки, а не закрывает
диалог.

## Темы

| Тема | Как выглядит |
|---|---|
| `rose` | по умолчанию: розово-белые тона, логотип на старте рисуется градиентом от белого к розовому |
| `dark` | тёмная: холодный синий акцент, приглушённые служебные строки |
| `night` | мягкие пастельные цвета — меньше контраста, удобно ночью |
| `light` | для светлого терминала |
| `mono` | без цвета, только яркость и начертание |

Тема запоминается в профиле. Цветность определяется сама: `COLORTERM` → truecolor,
`TERM` с `256` → 256 цветов, иначе 16; переменная `NO_COLOR` выключает цвет, а флаг
`--color none|16|256|truecolor` задаёт его вручную. Рамки и значки автоматически
заменяются на ASCII, если консоль не в UTF-8.

## Обычный режим (без полноэкранного интерфейса)

Включается сам, если вывод не в терминал, или флагом `--plain`, или если задача задана
в командной строке. Выглядит так:

```
  ✓ edit a.txt · замен 1 · 12→18
готово: исправил проверку на None и добавил тест

  итог: шагов 3 · вх 8.2K · вых 640 · списано 17 680 зачётных · 12.4с
  файлы: a.txt, test_a.py
```

Подтверждения в этом режиме спрашиваются в строке: `применить? [y/N/a=всегда]`.
При перенаправлении вывода в файл поток текста сохраняется, а управляющие коды не
пишутся вовсе.

## Что делать, если…

| Симптом | Действие |
|---|---|
| экран «поехал» | **Ctrl+L** |
| ввод «замерзал» после клика мышью по окну | в Windows ELYTRIX сам отключает QuickEdit-выделение консоли на время работы; если консоль замерла ещё до запуска — нажмите Esc или Enter в окне |
| картинка мерцает при печати | кадр перерисовывается дифференциально (только изменившиеся строки); на совсем древних консолях мерцание может остаться — выручает Windows Terminal |
| ввод «заикается» при печати | перерисовка ограничена 20 кадрами/с; классическая консоль (conhost) рисует медленнее, чем Windows Terminal — для плавности запускайте ELYTRIX в Windows Terminal, а `/doctor` подскажет, какой терминал обнаружен |
| окно намертво встаёт при вводе | в Windows ELYTRIX теперь читает клавиши классическим способом (без VT-ввода conhost); если вдруг повторится — запустите с `set ELYTRIX_LOG=%TEMP%\elytrix.log` и пришлите хвост файла: в нём видно последнее событие и размер кадра, на котором вывод встал |
| лента ушла вверх | **PageDown** до конца или `/clear` |
| агент долго думает | **Esc** — обрыв запроса; повтор обычно дешевле, чем ждать |
| правки не нужны | **Ctrl+C** — остановка задачи, затем `/undo` |
| не видно содержимого инструментов | **Ctrl+V** |
| терминал остался в полноэкранном режиме после падения | `reset` (Linux/macOS) или новое окно (Windows) |
