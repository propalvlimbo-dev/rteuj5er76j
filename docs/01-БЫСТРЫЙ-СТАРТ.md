# Быстрый старт: агент + ваш ключ SmartAPI

Весь проект заточен под один ключ `sk-smart-…` и один шлюз. Никакой ротации, регистраций
и десятка сервисов: ключ куплен — дальше только работа.

```
   agent / opencode / Cline / Kilo  (то, чем вы работаете)
                    │
                    ▼
      FreeCoder Router  127.0.0.1:8788        ← дневной лимит, учёт коэффициентов,
      (ваш компьютер, окно не закрывать)         и два адреса шлюза на случай сбоя
                    │
                    ▼
      https://api.smartapi.shop               ← ваш баланс 8 000 000
```

Зачем между ними прослойка, а не напрямую? Три причины, и все про деньги:

* **дневной лимит расхода** — баланс тратится ровно, а не сгорает за вечер;
* **учёт коэффициентов** — видно, сколько зачётных токенов ушло за сегодня;
* **два адреса шлюза** — если один формат перестанет отвечать, запрос уйдёт во второй,
  и вы этого не заметите.

---

## Что нужно

| Нужно | Зачем | Проверка |
|---|---|---|
| Windows 10/11 | проект и запускаторы под неё | — |
| Python 3.8+ | на нём роутер и агент | `python --version` |
| Ключ `sk-smart-…` | доступ к балансу | кабинет SmartAPI |

Больше ничего. Ни Node.js, ни Git, ни видеокарты, ни VS Code — всё опционально.
Зависимостей у проекта нет вообще, только стандартная библиотека Python.

## Установка

**1. Распакуйте папку проекта.**

Должно получиться так, чтобы внутри папки сразу лежали `app`, `config`, `docs`,
`START.bat`, `README.md` — без ещё одной вложенной папки.

**2. Проверьте Python** (в командной строке: `Win+R` → `cmd` → Enter):

```
python --version
```

Если пишет «не является внутренней или внешней командой» — поставьте Python с
<https://www.python.org/downloads/> и **обязательно отметьте галочку «Add Python to PATH»**.
После установки закройте и откройте командную строку заново.

**3. Возьмите ключ.** Кабинет → <https://smartapi.shop/api-keys> → создать ключ
(формат `sk-smart-…`). Если ключ уже где-то засветился — сначала отзовите его там же,
потом создайте новый. Подробности и про баланс — `docs/02-КЛЮЧ-БАЛАНС-ЛИМИТЫ.md`.

**4. Запустите одним файлом:**

```
двойной клик → START.bat
```

Что произойдёт:

1. спросит ключ — вставьте и нажмите Enter (сохранит в переменную окружения `SMARTAPI_KEY`,
   в следующий раз спрашивать не будет; в переписку и файлы ключ не попадает);
2. поднимет роутер (внутри того же окна) и дождётся, пока он ответит;
3. покажет модели — маршруты `auto` (Sonnet ×2), `cheap` (Luna ×1,7), `smart`, `max`
   и все модели шлюза, включая GPT; Enter — оставить `auto`; затем спросит **папку проекта** —
   путь к вашему коду; папка запоминается до следующего запуска;
4. запустит агента в этой папке: пишите задачи словами, он читает файлы и сам их правит.

Второго окна нет: роутер работает внутри запускатора, а расход печатается в строке каждого шага
(`сегодня 45.6K/400K`). Правки применяются сразу, откат — `/undo`.

> Windows может написать «Windows защитила ваш компьютер» — файл скачан из интернета. Нажмите
> «Подробнее» → «Выполнить в любом случае».

## Первая работа

Опишите задачу словами — агент сам найдёт нужные файлы и внесёт правки. Например:

```
в api.py функция get_user падает, если ответ пустой — сделай проверку и верни None
добавь тесты для parse_date: пустой ввод, кривой формат
добавь в index.html секцию с ценами: три тарифа, средний выделен
```

Освоиться проще на пустом проекте: скажите агенту «сделай папку demo с приветственной
страницей index.html» — получите `index.html` + `style.css`, которые открываются двойным
кликом, без интернета и хостинга.

Правки дальше пишутся словами прямо в окне агента:

```
добавь меню сверху
сделай блок с тремя карточками услуг
поменяй акцентный цвет на зелёный
```

Каждую правку агент покажет построчно и спросит подтверждение — отвечайте `y`.
Командный режим: `/diff` — что изменено, `/undo` — откатить, `/tokens` — расход на следующий
шаг, `/clear` — начать задачу без старой истории, `/model` — переключить модель (Claude, GPT, Codex).
на Opus для сложной задачи, `/exit` — выход.

Как ставить задачи по коду, чтобы получалось с первого раза — `docs/07-РАБОТА-С-МОИМ-КОДОМ.md`.
Про сайт отдельно — `docs/04-САЙТ-ЗА-ВЕЧЕР.md`.

## Другие способы работать (все ходят через тот же роутер)

| Инструмент | Запуск | Кому |
|---|---|---|
| Свой агент | `START.bat "задача"` | простой русскоязычный агент, ничего ставить не надо |
| opencode (TUI) | `config\opencode.json` | тем, кто любит терминальные агенты |
| Cline / Kilo Code / Continue в VS Code | см. `docs/03-ПОДКЛЮЧЕНИЕ-ПРИЛОЖЕНИЙ.md` | тем, кто хочет видеть diff в редакторе |
| Claude Code | тоже `docs/03` | если привыкли к нему |

Так как все они смотрят в роутер с одним и тем же лимитом, расход виден в одном месте —
в строке шага («сегодня 45.6K/400K»).

## Если не заработало

| Что видно | Что это значит | Что делать |
|---|---|---|
| `python не является внутренней командой` | Python не в PATH | переустановить с галочкой «Add Python to PATH», открыть новое окно |
| `502` + `HTTP 400 model does not exist` | шлюз не знает такой ID модели | команда /model в агенте печатает доступные модели — впишите нужную в `config/providers.json` |
| `404` на всех запросах | шлюз отвечает не в том формате | в конфиге уже есть второй формат (`smartapi-oai`) — он включён и подхватит работу |
| `401` / `403` | ключ неверный или отозван | проверить ключ в кабинете, создать новый |
| `429` сразу после старта | выбран дневной лимит расхода | подождать до полуночи по UTC или поднять `tpd` в `config/providers.json` |
| Модель не найдена | ID модели не совпадает с каталогом | взять имя со страницы «Модели» и поправить `config/providers.json` |
| Роутер не ответил за 40 секунд | ошибка при старте | откройте окно `FreeCoder Router` — там написана причина |
| Агент «не видит файлы» | проблема с ключом или контекстом | прогнать проверку ключа: `docs/06-ПРОВЕРКА-КЛЮЧА.md` |

Ещё есть два «диагностических» запуска без ключей вообще, чтобы убедиться, что программа жива:

```
python app\router.py --mock --port 8790     (роутер-заглушка)
python dev\tests\test_router.py                              (тесты роутера)
```
